Glossary / 100 terms

Video production glossary

One hundred working terms grouped by desk. Each has an actionable definition and a link to the relevant guide; where no guide exists, it goes to search.

100 terms

Story & Screenwriting 12

Logline一句话梗概

One sentence: who wants what, and what blocks them. If it takes a paragraph, the idea is not clear yet.

Read the guide

Three-act三幕

Setup, confrontation, resolution. A skeleton, not a law.

Read the guide

Storyboard分镜

Turning text into shootable shots, with size, action, and order.

Read the guide

Dialogue对白

What a character says out loud. Under every line, there should be something they want.

Read the guide

Subtext潜台词

The layer the line does not say, but the character is actually fighting for.

Read the guide

Want欲望

What the character must get in this scene. It has to be visible or audible.

Read the guide

Obstacle障碍

What blocks the want: time, distance, rules, or the character’s own fear.

Read the guide

Conflict冲突

Two valid reasons collide and only one result can stand. Volume is irrelevant.

Read the guide

Scene场景

One place, one stretch of time, one change. Without change, it is only footage.

Read the guide

Match on action动作匹配

Cut inside an action so two shots read as one continuous move.

Read the guide

Character arc人物弧光

Under the same pressure, the character’s choice changes, and they pay for it.

Read the guide

Voice-over旁白

A voice outside the frame. It gives a fact the picture cannot, or one person’s judgment. It does not summarize for the viewer.

Read the guide

Shooting 18

Exposure triangle曝光三角

Aperture, shutter, and ISO trade against each other. Protect the one you cannot lose.

Read the guide

Aperture光圈

Controls light and depth of field. Wider means a softer background.

Read the guide

Shutter快门

Sets exposure time and motion feel. Too fast kills motion blur.

Read the guide

ISOISO

How much the sensor amplifies light. Higher is brighter and noisier.

Read the guide

Lighting ratio灯比

The brightness difference between key and fill. 2:1 soft, 4:1 standard, 8:1 hard.

Read the guide

Key light主光

The light that shapes the face and sets the direction.

Read the guide

Color temperature色温

How warm or cool a light is, in kelvin. Keep it consistent within a film.

Read the guide

White balance白平衡

Keeping white white. Match skin first, then style.

Read the guide

180-degree line180° 线

An imaginary line between two people. Keep the camera on one side so the room stays clear.

Read the guide

Camera position机位

Where the camera sits relative to the subject. Moving it changes the audience’s relationship.

Read the guide

Set dressing场景陈设

Props, wear, and practical light that show who lived here, what just happened, and what is hidden.

Read the guide

Camera movement运镜

A motivated camera move: follow, reveal, or pressure. One per shot.

Read the guide

Continuity log场记单

The record of shot, take, and status. Without it, the edit cannot find anything.

Read the guide

Dual-system sound双系统录音

Picture and sound recorded separately, synced later with a clap or transient.

Read the guide

Continuity supervisor场记

The person tracking wardrobe, props, screen direction, and light so the takes cut together.

Read the guide

Camera height机位高度

How high the lens sits relative to the subject’s eyes. It sets who is big before it sets the shot size.

Read the guide

Focal length焦距

The lens decides how close the audience stands. Wide opens space; long presses the person into the background.

Read the guide

Shot size景别

The distance between viewer and person: wide for situation, full for action, medium for hands, close for hesitation, detail for one piece of information.

Read the guide

Post 18

Rough cut粗剪

Assemble the film so it can be watched end to end, exposing structural holes.

Read the guide

Fine cut细剪

Refine performance, breath, pacing, and transitions. Structure is no longer moving.

Read the guide

Cut point剪辑点

The frame where two shots meet. Put it where the audience wants the next second.

Read the guide

J-cut / L-cutJ-cut / L-cut

Sound enters early or leaves late, softening the picture cut.

Read the guide

Proxy代理文件

A low-bitrate copy for smooth editing. Delivery still uses the original.

Read the guide

Scopes示波器

Waveform, vectorscope, and other objective reads. Check them before trusting the feeling.

Read the guide

LUTLUT

A color lookup table. A starting point, not a magic filter.

Read the guide

Primary grade一级调色

Balance exposure, white, and contrast so one scene looks like one day.

Read the guide

Secondary grade二级调色

Change one color or one area without touching the whole frame.

Read the guide

Mix混音

Layer dialogue, room, music, and effects into one listenable track.

Read the guide

Subtitles字幕

Deliver the meaning to the eye before the ear falls behind. One thought per line, two lines max.

Read the guide

Loudness (LUFS)响度

Platforms measure overall loudness in LUFS. Peak level is not loudness.

Read the guide

FoleyFoley

Footsteps, cloth, and contact sounds performed and recorded in a studio.

Read the guide

Dialogue first对白优先

Make the voice clear first; music and effects move aside.

Read the guide

Cutting point接点

The frame where two shots meet. Action, eye line, or sound carries the viewer across.

Read the guide

Dialogue mix对白混音

Placing dialogue, music, and room tone at their proper levels. Dialogue stands first.

Read the guide

Room tone环境音

Thirty seconds of a space with no action. It stitches shots when dialogue breaks.

Read the guide

Transition转场

How two scenes connect. Answer how long and where first, then decide whether an effect is needed.

Read the guide

AI Video 11

First frame首帧

The starting image for image-to-video. It locks framing, light, and character.

Read the guide

Last frame尾帧

Where the motion must land. Lock the ends and the middle has a direction.

Read the guide

Character consistency角色一致性

Keeping the same face, wardrobe, and space across shots.

Read the guide

Scene anchor场景锚点

One sentence that locks door, window, table, and light direction; carry it into every new shot.

Read the guide

Reference image参考图

A fixed sample for the model. One clean front view beats ten noisy references.

Read the guide

Seed种子

The starting point for randomness. Fix it to compare two variables.

Read the guide

Digital human数字人

A presenter built from a real performance or generation. Consent and disclosure come before publishing.

Read the guide

Image-to-video图生视频

Generate motion from a still. Best when the frame is already decided.

Read the guide

Text-to-video文生视频

Generate from text alone. Less control, more rework. Write the action first.

Read the guide

Consent授权

Permission to use likeness, voice, and performance. A verbal yes is not enough.

Read the guide

AI disclosureAI 标注

Tell the audience when an image is generated or altered. Do not let it pose as a record.

Read the guide

Animation 10

Key frame关键帧

The essential poses. Set the keys, then fill the in-betweens.

Read the guide

In-between中间帧

The drawings between keys. They decide whether the action feels light or heavy.

Read the guide

Spacing时间间距

Distance between consecutive drawings. Same path, different spacing, different weight.

Read the guide

Lip sync口型

Land the closed consonants, then open on vowels. Four mouth shapes cover most dialogue.

Read the guide

Cycle循环

An action that loops cleanly: walk, run, breathe.

Read the guide

Blockout灰模

Simple boxes and spheres that lock timing, blocking, and camera.

Read the guide

Rig绑定

A skeleton that lets the model bend, turn, and perform.

Read the guide

Stop motion定格

Move a physical object frame by frame, then play it back. Two seconds a day is normal.

Read the guide

On twos / on ones12 格 / 24 格

Twelve or twenty-four drawings per second. Make the action read at the lowest count first.

Read the guide

Cel赛璐珞

The transparent sheet of early 2D animation. It separated character from background.

Read the guide

Formats 11

Talking head口播

One person delivers one argument to camera. The first three seconds and sentence density hold the viewer.

Read the guide

Product ad产品广告

Result, proof, one action.

Read the guide

Documentary short纪录短片

One person, one ongoing event, one change. No scripted lines.

Read the guide

Brand film品牌片

One person’s choice proves a sentence. The product is evidence.

Read the guide

Feed ad信息流

A vertical ad inside a content feed. The first three seconds must say “this is about me.”

Read the guide

Call to actionCTA

One action at the end: buy, tap, search, watch.

Read the guide

Short drama短剧

One location, two people, one information gap, one turn.

Read the guide

Vertical drama竖屏短剧

Drama shot for a vertical screen: face high, hands low, want and obstacle in the first three seconds.

Read the guide

VlogVlog

One person does one thing in one place: arrive, act, turn, leave.

Read the guide

Music videoMV

The track sets structure. Three visual motifs repeat and vary. Emotion before story.

Read the guide

Talking-head script口播稿

One person speaking to camera. It lives or dies on speakable sentences, not perfect diction.

Read the guide

Tools 12

Call sheet通告单

Who arrives where, when, with what, and who to call. One page.

Read the guide

Shot list拍摄清单

A must-get list ordered by camera and light, every row with a fallback.

Read the guide

Contingency预算缓冲

A separate ten percent with written rules for when it can and cannot move.

Read the guide

Location release场地许可

Written permission from the owner or manager covering hours, crew, power, noise, and cleanup.

Read the guide

3-2-1 backup3-2-1 备份

Three copies, two media types, one off-site.

Read the guide

Proxy workflow代理工作流

Low-bitrate copies plus a relink path for editing. Delivery goes back to the original.

Read the guide

Delivery bitrate交付码率

The data rate a platform accepts. Read the spec before chasing quality.

Read the guide

Call sheet update通告变更页

The day’s shared page of times, places, contacts, and changes. Not a formality.

Read the guide

Budget预算表

Split must-pay, on-screen, swappable, and buffer, and decide in advance what can be cut.

Read the guide

Stripboard拆条

Break the script into strips by location, day or night, and cast, then build shoot days.

Read the guide

Audition试镜

Give the actor an action, not a monologue. Watch for a real response inside the doing.

Read the guide

Delivery spec交付规格

The ratio, resolution, frame rate, bitrate, color, audio, and filename a platform or client requires. Write it into a sheet first.

Read the guide

History & Literacy 8

Daguerreotype达盖尔法

The silver-plate process announced in 1839. Images became reproducible, and alterable.

Read the guide

Montage蒙太奇

Two unrelated shots placed together so the audience makes a third meaning.

Read the guide

Media literacy媒介素养

When you see a video, ask who made it, what was removed, and what it wants you to believe.

Read the guide

Likeness rights肖像权

Using a person’s face and voice needs permission, including where it will be published.

Read the guide

CC BY-SACC BY-SA

Credit the author and share under the same terms. It is not public domain.

Read the guide

AI traceAI 痕迹

Odd hands, text, physics, or reflections. A trace does not prove the whole image is fake.

Read the guide

Platform ranking平台推荐

Completion, engagement, and dwell time decide who sees what. The platform is also editing your world.

Read the guide

Viewing distance观看距离

How far the viewer sits from the screen. Closer viewing pulls the framing tighter and kills the wide shot.
