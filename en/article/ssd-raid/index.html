SSD RAID: Edit Array, Not Archive

SSD RAID is an edit workspace, not an archive; rebuilding costs more than backup.

With one array and no offline backup, do not make it the only media library. RAID solves speed or a single-drive failure, not “the whole project disappeared.”

Separate RAID from backup

  • RAID 0: speed stacks, risk stacks; one drive failure can make the whole set unreadable. Use it only for regenerable cache.
  • RAID 1/5/6: redundancy is still not backup; a controller failure, deletion or ransomware hits the whole array.
  • Interface and cooling: confirm Thunderbolt/USB version, sustained write and cooling; a hot editing array throttles.

When not to use it

On set

Use RAID 0 only for working media and keep a RAID 1 or NAS as backup. Run a full-disk test and watch for slowdown.

Do this

SSD RAID is a editing work disk, not an archive; when the array dies, rebuilding costs more than backup.

  1. Build RAID 0 for working media only.
  2. Set RAID 1 or NAS for backup.
  3. Fill the drive and measure the speed drop.

Avoid

Do not make RAID 0 the only storage; one drive failure takes all media.

Three causes

For “SSD RAID: Edit Array, Not Archive”, check three directions first. Change one variable, record a 30-second comparison, and see which link the change follows.

CauseSignal on setFive-minute test
RAID 0 as the only copyOne drive fails and all footage is goneUse RAID 0 as a working disk, never as backup
Interface too slowUSB 10Gbps cannot feed a multi-drive arrayMatch host port and cable
Poor coolingSustained writes throttle and the edit stuttersRun a thirty-minute sustained write test

On-set diagnosis

  1. Measure sustained read/write with AJA or Blackmagic, not peak burst only.
  2. Write for thirty minutes and log speed, temperature and dropout.
  3. Confirm an independent backup exists and a restore has been rehearsed.

Fix

RAID is an availability and speed tool, not a backup. Secure one independent copy before discussing an array.

  1. Use a two-drive RAID 0 as the working disk and a separate drive/NAS as backup.
  2. Use 10Gbps or faster; match cable and expansion card.
  3. Leave cooling space around the array; do not stack drives.
  4. Rehearse a restore monthly with a random file.

Failure cases

With “SSD RAID: Edit Array, Not Archive”, these three moves make it worse. Pick one replacement action and do not change three variables at once.

One line for the set

RAID 0 is for speed; backup is for survival. They are not the same job.
