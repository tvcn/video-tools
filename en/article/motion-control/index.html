Motion Control: Give the Camera a Route

Give the camera a route: where it starts, what it passes, where it stops. "Camera moves" says nothing.

Lock the path, then the speed

Motion control has two layers: the path an object takes and how long it stays at each point. Path sets space; speed sets weight. Draw the path, then the curve; do not just pile keyframes.

Test with a car or ball: fix the path, add ease-in/out; a wrong speed curve looks like sliding on ice.

Limits

More keys is not better. Too many keys stutter; set big poses, then in-betweens.

First/last frame and camera control: decide what must not move

The control point in image-to-video is not “make it move,” but what stays fixed. Lock at least two of: identity, product logo, background structure. Release everything and the model improvises.

First frameLock composition, light, wardrobeA soft first frame drifts throughout

Camera“Push/pull/track + speed”“Cool camera move” cannot execute

Project-level checks

  1. Use a final-quality first frame, not a blurry screenshot; the model treats blur as style.
  2. Write speed as “push in 10% over three seconds,” not “slow push.”
  3. Check edges, fingers and text in motion; if they tear, reduce the move.
  4. Add a mid-reference between first and last frame; long shots drift less.

If the client sends a low-resolution product image, reshoot or rebuild the first frame. Do not gamble on bad input.

On set

Write the camera path: push from the door to one meter from the table, hold two seconds. Use a reference video or keyframes; do not just say orbit.

Do this

Motion control starts with a camera path: where it starts, what it passes, where it stops. “Camera moves” says nothing.

  1. Write the path: push from the door to one meter from the table, hold two seconds.
  2. Control with a reference video or keyframes, not just “orbit.”
  3. Run three times to confirm the path repeats before changing a variable.

Avoid

Do not write only “orbit” or “push”; without start and stop, the model wanders.

3 checks

  • The prompt states start, path, and stop and can be drawn as a line.
  • All three outputs reach the same endpoint without changing direction mid-shot.
  • When speed or lens changes, the path itself still repeats.
