A workstation is not a spec sheet; NLE, proxies, cache and nodes must not fight in one project. One page of &quot;Choosing an NLE: Start With the Project&quot; solves one local problem; joining &quot;Choosing an NLE: Start With the Project&quot;, &quot;Proxy Creation: Match the Timeline&quot; and &quot;DaVinci Nodes: Nodes Are Not Filters&quot; exposes the real failure: conditions are missing, too many variables move, and the result cannot be reproduced.

Problem

The problem is not a lack of methods; each step works alone, but together they fail because the condition was not written, too many variables moved and the result cannot be reproduced.

The order is condition, judgement, one variable and evidence. A step is complete only when the next person can repeat it.

Judgement

  • First gate in "Choosing an NLE: Start With the Project": One minute is cut in three apps from the same footage.
  • Second gate in "Proxy Creation: Match the Timeline": Proxies, collaboration, subtitles, and export are compared.
  • Third gate in "DaVinci Nodes: Nodes Are Not Filters": The choice follows the project's weakest need, not popularity.

If one gate fails, return to its single page; do not hide an unsolved point inside a longer chain.

Method

  1. Write the condition first: turn "Cut one minute of the same footage in three apps." from "Choosing an NLE: Start With the Project" into three rows: material, environment, acceptance.
  2. Run one minimal action: follow "Choosing an NLE: Start With the Project" for 30 seconds and do not add the second page yet.
  3. Attach the second page: Compare proxies, collaboration, subtitles, and export..
  4. Use the third page as a control: Decide by the project's weakest requirement..
  5. Change one variable at a time; write the other conditions down instead of remembering them.
  6. Film the failure too: put failure and success side by side to see which step cannot be skipped.
  7. Ask the next person to reproduce from the record; if they cannot, the record is not finished.

Field test

A reproducible test, not a client case: take 30 seconds of material, make version A using "One minute is cut in three apps from the same footage." from "Choosing an NLE: Start With the Project", then version B using "Proxies, collaboration, subtitles, and export are compared." from "Proxy Creation: Match the Timeline"; only one variable may differ. Put them side by side and record what breaks first in "DaVinci Nodes: Nodes Are Not Filters": condition, action or acceptance. If it works on the first try, add one real constraint and run it again.

Acceptance

  • One minute is cut in three apps from the same footage.
  • Proxies, collaboration, subtitles, and export are compared.
  • The choice follows the project's weakest need, not popularity.
  • Proxies are quarter-resolution ProRes Proxy on a separate SSD.
  • Timeline and proxy names map back to originals.
  • After relink, timecode and framing match the proxy cut.
  • Five nodes each do one job with clear names.
  • Toggling each shows its specific change.
  • No more than ten nodes, and problems map to one node.
  • The condition from Choosing an NLE: Start With the Project fits on one line and can be repeated by someone else.

Alternatives

  • For a single-point problem in "Choosing an NLE: Start With the Project", go back to Choosing an NLE: Start With the Project; do not use the whole chain.
  • To compare two actions, read Proxy Creation: Match the Timeline and leave the third page alone.
  • For acceptance only, use DaVinci Nodes: Nodes Are Not Filters as a self-test sheet.
