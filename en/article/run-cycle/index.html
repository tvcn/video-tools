Run Cycle: Feet and Center of Gravity

Set the center of gravity and footfall order before arms; wrong feet make the whole body float.

Run cycles start at the contact frame

The key is not how high the leg lifts but when the foot lands and when the body is lowest. Mark contact and airborne frames, then in-between; a wrong contact makes the whole cycle slide.

Check in side view: head bounce, hip sway, arms opposing legs. If one is wrong, the cycle is unstable.

Limits

Running is not fast walking. Walking always has a foot down; running has flight. Speed up a walk cycle and it becomes race-walking.

On set

Draw four key poses: contact, down, pass, and airborne. Roll the foot heel to toe and keep the hips within one head height.

Do this

A run cycle fixes weight and foot contact before arms; wrong feet make the whole body float.

  1. Draw four key poses: contact, down, passing, airborne.
  2. Roll the foot from heel to toe.
  3. Keep vertical travel within one head height, then fix arms.

Avoid

Do not fix arms first; sliding feet make even smooth arms look floaty.

3 checks

  • All four key poses read: contact, down, passing, airborne.
  • The planted foot rolls heel to toe instead of sliding flat.
  • Vertical travel stays within one head and the loop does not float.
