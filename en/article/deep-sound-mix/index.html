Mixing is not making it louder; dialogue, loudness and foley need their places so the audience is not tired. One page of "Sound Post: The Order from Dialogue to Final Mix" solves one local problem; joining "Sound Post: The Order from Dialogue to Final Mix", "Loudness: Platform Target and True Peak" and "Foley: Steps, Cloth, Doors" exposes the real failure: conditions are missing, too many variables move, and the result cannot be reproduced.

Problem

The problem is not a lack of methods; each step works alone, but together they fail because the condition was not written, too many variables moved and the result cannot be reproduced.

The order is condition, judgement, one variable and evidence. A step is complete only when the next person can repeat it.

Judgement

  • First gate in "Sound Post: The Order from Dialogue to Final Mix": Dialogue is clear without captions.
  • Second gate in "Loudness: Platform Target and True Peak": Ambience is continuous across every cut.
  • Third gate in "Foley: Steps, Cloth, Doors": Effects match screen direction.

If one gate fails, return to its single page; do not hide an unsolved point inside a longer chain.

Method

  1. Write the condition first: turn "Mix to the platform target, commonly -14 LUFS." from "Sound Post: The Order from Dialogue to Final Mix" into three rows: material, environment, acceptance.
  2. Run one minimal action: follow "Sound Post: The Order from Dialogue to Final Mix" for 30 seconds and do not add the second page yet.
  3. Attach the second page: Set true peak at -1 dB and leave another 0.5 to 1 dB of margin..
  4. Use the third page as a control: Do not slam the limiter; go back to dialogue and dynamics..
  5. Change one variable at a time; write the other conditions down instead of remembering them.
  6. Film the failure too: put failure and success side by side to see which step cannot be skipped.
  7. Ask the next person to reproduce from the record; if they cannot, the record is not finished.

Field test

A reproducible test, not a client case: take 30 seconds of material, make version A using "Dialogue is clear without captions." from "Sound Post: The Order from Dialogue to Final Mix", then version B using "Ambience is continuous across every cut." from "Loudness: Platform Target and True Peak"; only one variable may differ. Put them side by side and record what breaks first in "Foley: Steps, Cloth, Doors": condition, action or acceptance. If it works on the first try, add one real constraint and run it again.

Acceptance

  • Dialogue is clear without captions.
  • Ambience is continuous across every cut.
  • Effects match screen direction.
  • Music never buries a key line.
  • Loudness matches platform; three devices checked.
  • DX/AMB/SFX/MX delivered as stems.
  • Integrated loudness sits near the platform target, not guessed by ear.
  • True peak stays at or below -1 dB with no continuous red.
  • Dialogue stays clear and music or ambience does not flatten the dynamics.
  • Solo dialogue and confirm every line is intelligible

Alternatives

  • For a single-point problem in "Sound Post: The Order from Dialogue to Final Mix", go back to Sound Post: The Order from Dialogue to Final Mix; do not use the whole chain.
  • To compare two actions, read Loudness: Platform Target and True Peak and leave the third page alone.
  • For acceptance only, use Foley: Steps, Cloth, Doors as a self-test sheet.
