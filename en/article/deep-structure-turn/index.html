Structure turn: midpoint, ending, format

Structure is not a three-act template; the midpoint turns direction and the ending charges for the choice. One page of &quot;Midpoint Turn: Change the Method, Not the Goal&quot; solves one local problem; joining &quot;Midpoint Turn: Change the Method, Not the Goal&quot;, &quot;Ending: Stop After the Choice&quot; and &quot;Script Format: Make the Whole Crew Read It the Same Way&quot; exposes the real failure: conditions are missing, too many variables move, and the result cannot be reproduced.

Problem

The problem is not a lack of methods; each step works alone, but together they fail because the condition was not written, too many variables moved and the result cannot be reproduced.

The order is condition, judgement, one variable and evidence. A step is complete only when the next person can repeat it.

Judgement

  • First gate in "Midpoint Turn: Change the Method, Not the Goal": The goal line is identical before and after midpoint; it is not swapped.
  • Second gate in "Ending: Stop After the Choice": Each column has three filmable actions and the methods look different.
  • Third gate in "Script Format: Make the Whole Crew Read It the Same Way": Without dialogue, the audience can name what method changed.

If one gate fails, return to its single page; do not hide an unsolved point inside a longer chain.

Method

  1. Write the condition first: turn "Use one A4: old method on the left, new method on the right, goal unchanged abov…" from "Midpoint Turn: Change the Method, Not the Goal" into three rows: material, environment, acceptance.
  2. Run one minimal action: follow "Midpoint Turn: Change the Method, Not the Goal" for 30 seconds and do not add the second page yet.
  3. Attach the second page: Write three concrete actions per column that look different on screen..
  4. Use the third page as a control: Shoot the difference so the audience sees the method change, not hears “I change….
  5. Change one variable at a time; write the other conditions down instead of remembering them.
  6. Film the failure too: put failure and success side by side to see which step cannot be skipped.
  7. Ask the next person to reproduce from the record; if they cannot, the record is not finished.

Field test

A reproducible test, not a client case: take 30 seconds of material, make version A using "The goal line is identical before and after midpoint; it is not s…" from "Midpoint Turn: Change the Method, Not the Goal", then version B using "Each column has three filmable actions and the methods look diffe…" from "Ending: Stop After the Choice"; only one variable may differ. Put them side by side and record what breaks first in "Script Format: Make the Whole Crew Read It the Same Way": condition, action or acceptance. If it works on the first try, add one real constraint and run it again.

Acceptance

  • The goal line is identical before and after midpoint; it is not swapped.
  • Each column has three filmable actions and the methods look different.
  • Without dialogue, the audience can name what method changed.
  • Method changes, not goal
  • The old method worked first
  • The midpoint proves it fails
  • The new method has a learning cost
  • The cost is filmable
  • The final shot is an action after the choice with no explanatory voice-over.
  • The audience can name what was chosen and what was given up.

Alternatives

  • For a single-point problem in "Midpoint Turn: Change the Method, Not the Goal", go back to Midpoint Turn: Change the Method, Not the Goal; do not use the whole chain.
  • To compare two actions, read Ending: Stop After the Choice and leave the third page alone.
  • For acceptance only, use Script Format: Make the Whole Crew Read It the Same Way as a self-test sheet.
