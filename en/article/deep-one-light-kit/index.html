One light is enough only when soft area, bounce position and colour temperature agree. One page of &quot;One-Light Portrait: Direction First&quot; solves one local problem; joining &quot;One-Light Portrait: Direction First&quot;, &quot;Softbox: Size Decides Softness&quot; and &quot;Reflector: Five Surfaces, One Job&quot; exposes the real failure: conditions are missing, too many variables move, and the result cannot be reproduced.

Problem

The problem is not a lack of methods; each step works alone, but together they fail because the condition was not written, too many variables moved and the result cannot be reproduced.

The order is condition, judgement, one variable and evidence. A step is complete only when the next person can repeat it.

Judgement

  • First gate in "One-Light Portrait: Direction First": The light sits at 45 degrees, one meter away, with position logged.
  • Second gate in "Softbox: Size Decides Softness": The nose shadow clearly shows light direction.
  • Third gate in "Reflector: Five Surfaces, One Job": Softbox size is chosen after direction is confirmed.

If one gate fails, return to its single page; do not hide an unsolved point inside a longer chain.

Method

  1. Write the condition first: turn "Place the light at 45 degrees, one meter from the face." from "One-Light Portrait: Direction First" into three rows: material, environment, acceptance.
  2. Run one minimal action: follow "One-Light Portrait: Direction First" for 30 seconds and do not add the second page yet.
  3. Attach the second page: Shoot one frame and watch the nose shadow..
  4. Use the third page as a control: Then decide the softbox size..
  5. Change one variable at a time; write the other conditions down instead of remembering them.
  6. Film the failure too: put failure and success side by side to see which step cannot be skipped.
  7. Ask the next person to reproduce from the record; if they cannot, the record is not finished.

Field test

A reproducible test, not a client case: take 30 seconds of material, make version A using "The light sits at 45 degrees, one meter away, with position logge…" from "One-Light Portrait: Direction First", then version B using "The nose shadow clearly shows light direction." from "Softbox: Size Decides Softness"; only one variable may differ. Put them side by side and record what breaks first in "Reflector: Five Surfaces, One Job": condition, action or acceptance. If it works on the first try, add one real constraint and run it again.

Acceptance

  • The light sits at 45 degrees, one meter away, with position logged.
  • The nose shadow clearly shows light direction.
  • Softbox size is chosen after direction is confirmed.
  • 0.8 m and 1.5 m samples use the same light.
  • The closer frame has visibly softer shadow edges.
  • Eye-light size changes with distance and is compared.
  • A white-side 45-degree fill sample exists.
  • Silver is used only after white proves insufficient, with a comparison.
  • Gold is not default, or its warmth is justified.
  • The condition from One-Light Portrait: Direction First fits on one line and can be repeated by someone else.

Alternatives

  • For a single-point problem in "One-Light Portrait: Direction First", go back to One-Light Portrait: Direction First; do not use the whole chain.
  • To compare two actions, read Softbox: Size Decides Softness and leave the third page alone.
  • For acceptance only, use Reflector: Five Surfaces, One Job as a self-test sheet.
