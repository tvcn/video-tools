Stop-Motion Set: Scale and Perspective

Set puppet scale first, then build to camera perspective. Wrong scale looks fake in any light.

It is not a miniature landscape. Every adjustable position needs two fingers of access; walls, furniture and floor must come apart separately or one touch collapses the set.

A stop-motion set must fit a hand

Build a paper maquette at 1:6 or 1:12 first, checking camera, lamp and hand space; do not start with detail.

Limits

More set is not better. Keep foreground for blocking and background empty so a hand fits; a packed set leaves no room even to focus.

Stop-motion sets: scale first, light second

A stop-motion set is not a miniature real world. It is a workbench a hand must fit into. Scale, depth of field and light stability decide quality earlier than fine detail.

ItemOn-set practiceFailure signal
ScaleChoose 1:6 or 1:12; all props share itHand and prop scale disagree
DepthSmall aperture + enough lightSubject sharp, set mush
LightLock positions, use flags, no auto exposureBrightness jumps between frames
ReplacementsTwo or three mouths/hands per actionRun out mid-shot

Project-level checks

  1. Shoot a ten-frame test: does the hand block light or hit the set?
  2. Clamp every light and mark its position; after a move you must return to the same mark.
  3. Lock exposure and white balance in the capture software; disable camera automation.
  4. Back up after every shot. One lost frame means reshooting the whole section.

If a hand enters frame, rehearse the move. The hand is the prop most likely to break the illusion.

On set

Measure the puppet height, then size the set to the lens perspective. Run one perspective line from camera to background and align everything to it.

Do this

Stop-motion sets scale from the puppet and shot perspective; wrong scale looks fake under any light.

  1. Measure the puppet height.
  2. Calculate set size from the shot perspective.
  3. Run one perspective line from camera to background and align everything.

Avoid

Do not build the set by feel; one door next to the puppet reveals the scale.

Judge

Three signals are observable on set:

  • the speed split between foreground, midground and background reads in one pan
  • a 0.5-second action still carries weight or anticipation
  • turn off any layer and the space still holds

Failures

These three moves erase the detail you just built:

  • more layers, same speed: the space stays flat
  • anticipation without follow-through: the weight is only half done
  • rendering before assets are locked: rework starts at the compositor

Extend

10-minute exercise: Draw three keys at 24 fps, change only “Calculate set size from the shot perspective.”, and export two seconds. If the weight still does not read, add anticipation before adding blur.

3 checks

  • Puppet height and set size have a conversion record.
  • One perspective line runs camera to background and key objects align.
  • The puppet reads correctly beside door and table without hiding it.
