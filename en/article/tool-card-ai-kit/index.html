AI Workflow Kit

AI workflow: script, reference, generator, upscale, comp, disclosure; every step reversible.

3 min read · Field noteTVCN EditorialEdited 2026-11

Lock what must not change

An AI workflow is not “one prompt and a finished film.” Lock the script, character bible, shot list, rights scope and delivery specs before deciding which shots to generate.

  • Minimum: one usable generator, a set of character references, an upscale/repair tool, an editor and a rights log.
  • Working: character sheet, shot-prompt template, generated-asset IDs, compositing and grade, human check list.
  • Insured: local backups, model/version records and a live-action fallback; a failed generation does not stop the project.

Use it where it is controllable

Start with inserts, backgrounds, concept frames and pickups; do not start with a hero close-up and long dialogue. Hands, text, fast motion, mirrors and complex occlusion remain high-risk.

Three checks

  1. The same character across three angles keeps face, hair, wardrobe and light direction.
  2. A continuous five-second move shows no warping, flicker or limb fusion.
  3. Output files, model version, prompts and rights sources are all findable in the project record.

When not to use it

News, documentary, testimony, real-person endorsement and projects requiring clear authorship must not use generated images as on-set evidence. Assets without a rights chain do not enter delivery.

On set

Script, reference, generator, upscale, comp, and label. Keep a rollback version at every step.

Avoid

Do not keep rerolling generations; without script and references, a good roll is still unusable.

Image note. Covers, diagrams and step images on this page are editorial illustrations or structure diagrams, not photographs of a test performed here; they are not evidence of measured gear performance. Where an image is AI-assisted, the caption says so. Read the test conditions in the text before treating an image as proof.

3 checks

  • Script and references exist before the first generation.
  • Generation, upscale, and comp each carry a rollback version.
  • The delivered version has an AI label and a traceable version chain.
