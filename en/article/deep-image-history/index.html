Image history is not a year list; 1839, 1895 and photography together show how recording became narrative. One page of "1839" solves one local problem; joining "1839", "1895" and "photo-history" exposes the real failure: conditions are missing, too many variables move, and the result cannot be reproduced.

Problem

The problem is not a lack of methods; each step works alone, but together they fail because the condition was not written, too many variables moved and the result cannot be reproduced.

The order is condition, judgement, one variable and evidence. A step is complete only when the next person can repeat it.

Judgement

  • First gate in "1839": The condition from 1839 fits on one line and can be repeated by someone else.
  • Second gate in "1895": Only one variable changes and the other page's result still reproduces.
  • Third gate in "photo-history": A failure is recorded as condition, action and result, not a feeling.

If one gate fails, return to its single page; do not hide an unsolved point inside a longer chain.

Method

  1. Write the condition first: turn "can or cannot" from "1839" into three rows: material, environment, acceptance.
  2. Run one minimal action: follow "1839" for 30 seconds and do not add the second page yet.
  3. Attach the second page: change one variable and hold everything else.
  4. Use the third page as a control: shoot a same-condition version and compare.
  5. Change one variable at a time; write the other conditions down instead of remembering them.
  6. Film the failure too: put failure and success side by side to see which step cannot be skipped.
  7. Ask the next person to reproduce from the record; if they cannot, the record is not finished.

Field test

A reproducible test, not a client case: take 30 seconds of material, make version A using "The condition from 1839 fits on one line and can be repeated by s…" from "1839", then version B using "Only one variable changes and the other page's result still repro…" from "1895"; only one variable may differ. Put them side by side and record what breaks first in "photo-history": condition, action or acceptance. If it works on the first try, add one real constraint and run it again.

Acceptance

  • The condition from 1839 fits on one line and can be repeated by someone else.
  • Only one variable changes and the other page's result still reproduces.
  • A failure is recorded as condition, action and result, not a feeling.
  • A colleague can reproduce the same version without asking you.

Alternatives

  • For a single-point problem in "1839", go back to 1839; do not use the whole chain.
  • To compare two actions, read 1895 and leave the third page alone.
  • For acceptance only, use photo-history as a self-test sheet.

Boundary

This chain is not evidence that one image regime is more real than another. Between 1839 and 1895, recording, projection and viewing institutions changed separately; compressing three nodes into one causal chain erases regional practice. The page treats the nodes as three samples of how recording becomes narrative, not as a timeline.
