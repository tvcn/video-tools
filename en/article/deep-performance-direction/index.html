Performance direction: rehearsal, notes, scale

Direction is not shouting one more; it turns action, intention and scale into playable notes.

Direction is not shouting one more; it turns action, intention and scale into playable notes. One page of "Rehearsal: Block First, Lines Later" solves one local problem; joining "Rehearsal: Block First, Lines Later", "Notes to Actors: One Executable Sentence" and "Performance Scale: Closer Camera, Smaller Action" exposes the real failure: conditions are missing, too many variables move, and the result cannot be reproduced.

Problem

The problem is not a lack of methods; each step works alone, but together they fail because the condition was not written, too many variables moved and the result cannot be reproduced.

The order is condition, judgement, one variable and evidence. A step is complete only when the next person can repeat it.

Judgement

  • First gate in "Rehearsal: Block First, Lines Later": The first two passes have no lines, only positions and actions.
  • Second gate in "Notes to Actors: One Executable Sentence": On the third pass, pauses still land on actions.
  • Third gate in "Performance Scale: Closer Camera, Smaller Action": The actor can state what they want throughout the scene.

If one gate fails, return to its single page; do not hide an unsolved point inside a longer chain.

Method

  1. Write the condition first: turn "Spend the first twenty minutes on blocking only, taping door, chair, and camera." from "Rehearsal: Block First, Lines Later" into three rows: material, environment, acceptance.
  2. Run one minimal action: follow "Rehearsal: Block First, Lines Later" for 30 seconds and do not add the second page yet.
  3. Attach the second page: Walk the actor through three times without lines, only action and pauses..
  4. Use the third page as a control: Add lines on the third pass and confirm they land on established positions..
  5. Change one variable at a time; write the other conditions down instead of remembering them.
  6. Film the failure too: put failure and success side by side to see which step cannot be skipped.
  7. Ask the next person to reproduce from the record; if they cannot, the record is not finished.

Field test

A reproducible test, not a client case: take 30 seconds of material, make version A using "The first two passes have no lines, only positions and actions." from "Rehearsal: Block First, Lines Later", then version B using "On the third pass, pauses still land on actions." from "Notes to Actors: One Executable Sentence"; only one variable may differ. Put them side by side and record what breaks first in "Performance Scale: Closer Camera, Smaller Action": condition, action or acceptance. If it works on the first try, add one real constraint and run it again.

Acceptance

  • The first two passes have no lines, only positions and actions.
  • On the third pass, pauses still land on actions.
  • The actor can state what they want throughout the scene.
  • Walked once without lines
  • Marked start, end, and turns
  • Tested sitting and standing
  • Touched every prop once
  • Gave verbs, not adjectives
  • Each note contains one executable action.
  • The actor can do it immediately without asking “how exactly.”

Alternatives

  • For a single-point problem in "Rehearsal: Block First, Lines Later", go back to Rehearsal: Block First, Lines Later; do not use the whole chain.
  • To compare two actions, read Notes to Actors: One Executable Sentence and leave the third page alone.
  • For acceptance only, use Performance Scale: Closer Camera, Smaller Action as a self-test sheet.
