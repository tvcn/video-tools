How we test AI video models

Same prompt, references, resolution and run count; six shot classes, three runs each, at least two blind raters. Scores belong to that batch, not a cross-batch leaderboard.

Fit and no-fit / 适用与不适用

  • Readers asking what evidence supports a model claim.
  • Creators/vendors wanting to reproduce or submit samples.
  • Not for: people wanting a permanent leaderboard.

Do this / 怎么做

  1. Pick six classes: face, hands, motion, product, text, long take.
  2. Freeze each prompt: subject/action/light/camera/duration.
  3. Three runs per model per class; log failure type.
  4. At least two blind raters, 1–5, without model names.
  5. Publish batch date, model version and price read date.

Avoid / 别踩

  • Showing the best clip only; that is an ad, not a test.
  • Different prompts per model; scores are not comparable.
  • Treating one batch as permanent; versions/prices change monthly.

Go deeper / 继续往下

The protocol's first value is reproducibility, not a verdict. Same prompt, references, resolution and runs; change one and scores are incomparable. We publish prompt, references, model version and failure type so readers can rerun.

Blind rating removes brand bias. Hide model names and give only clips and a score sheet; if two raters differ by more than two points, calibrate the rubric before continuing.

Checks / 验收

  • Six classes, three runs, two blind raters recorded.
  • Failure types defined, not just “bad.”
  • Model version, date and price read date published.
  • Page states no cross-batch leaderboard.
