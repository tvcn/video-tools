Set safety: risk, permit, wrap

Set safety is not a signature; risk, permit and wrap checks must reach every moving person.

Set safety is not a signature; risk, permit and wrap checks must reach every moving person. One page of "Set Safety: Cables, Heights, Roads" solves one local problem; joining "Set Safety: Cables, Heights, Roads", "Risk Assessment: Fill One Page Before You Roll" and "Permits: Parks, Transit, Shops" exposes the real failure: conditions are missing, too many variables move, and the result cannot be reproduced.

Problem

The problem is not a lack of methods; each step works alone, but together they fail because the condition was not written, too many variables moved and the result cannot be reproduced.

The order is condition, judgement, one variable and evidence. A step is complete only when the next person can repeat it.

Judgement

  • First gate in "Set Safety: Cables, Heights, Roads": No cable crosses a walkway untaped and every stand is sandbagged.
  • Second gate in "Risk Assessment: Fill One Page Before You Roll": High stands have a spotter and everyone near the road wears hi-vis.
  • Third gate in "Permits: Parks, Transit, Shops": Any crew member can name the nearest hospital, assembly point, and on-set contact.

If one gate fails, return to its single page; do not hide an unsolved point inside a longer chain.

Method

  1. Write the condition first: turn "Tape cables flat across walkways and sandbag every light stand." from "Set Safety: Cables, Heights, Roads" into three rows: material, environment, acceptance.
  2. Run one minimal action: follow "Set Safety: Cables, Heights, Roads" for 30 seconds and do not add the second page yet.
  3. Attach the second page: Put a person on high stands and wear hi-vis near roads..
  4. Use the third page as a control: Put the nearest hospital, assembly point, and contact in the call sheet and read….
  5. Change one variable at a time; write the other conditions down instead of remembering them.
  6. Film the failure too: put failure and success side by side to see which step cannot be skipped.
  7. Ask the next person to reproduce from the record; if they cannot, the record is not finished.

Field test

A reproducible test, not a client case: take 30 seconds of material, make version A using "No cable crosses a walkway untaped and every stand is sandbagged." from "Set Safety: Cables, Heights, Roads", then version B using "High stands have a spotter and everyone near the road wears hi-vi…" from "Risk Assessment: Fill One Page Before You Roll"; only one variable may differ. Put them side by side and record what breaks first in "Permits: Parks, Transit, Shops": condition, action or acceptance. If it works on the first try, add one real constraint and run it again.

Acceptance

  • No cable crosses a walkway untaped and every stand is sandbagged.
  • High stands have a spotter and everyone near the road wears hi-vis.
  • Any crew member can name the nearest hospital, assembly point, and on-set contact.
  • Tape every cable
  • Keep the walkway clear
  • No chairs as stands
  • Do not overload power strips
  • Someone holds the ladder
  • All four boxes contain specifics, not “be careful.”
  • Every risk has a named owner and crew can state their own item.

Alternatives

  • For a single-point problem in "Set Safety: Cables, Heights, Roads", go back to Set Safety: Cables, Heights, Roads; do not use the whole chain.
  • To compare two actions, read Risk Assessment: Fill One Page Before You Roll and leave the third page alone.
  • For acceptance only, use Permits: Parks, Transit, Shops as a self-test sheet.
