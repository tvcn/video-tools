AI cleanup and set extension

Cleanup starts with a rebuildable background. Remove pedestrians, wires or mistakes only with a clean plate, tracking and occlusion; AI is not a magic eraser.

Fit and no-fit / 适用与不适用

  • Remove pedestrians, wires, mistakes or clutter.
  • Extending frame edges to a larger format.
  • Not for: large subject occlusion with no clean background.

Do this / 怎么做

  1. Shoot/find a clean plate: same camera, same light.
  2. Track camera motion; draw roto/masks.
  3. Fix ten frames; check edges/texture/light.
  4. Run the full shot; check flicker in sections.
  5. Comp back; check grain/color/motion blur.

Avoid / 别踩

  • Erasing without a clean plate; background smears.
  • Fixing one frame; flicker on playback.
  • Not matching grain/motion blur; comp looks fake.

Go deeper / 继续往下

The most underestimated part is background. A pedestrian blocks 20 frames; the model must invent floor/wall/texture. Without a clean plate it guesses, and the guessed texture flickers.

Set extension is more perspective-sensitive than cleanup. Lock camera path, lens and vanishing point before generating edges; otherwise the extended wall does not match and viewers see the frame widen.

Checks / 验收

  • Clean plate shares camera/light.
  • Roto/track covers the full move.
  • No flicker/smear across 20 frames.
  • Grain/color/motion blur match source.
