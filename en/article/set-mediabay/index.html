Media Bay: Offload and Name on Set

Offload, verify, name, and back up on set; organizing later doubles the time.

Offloading is not dragging a folder. Use a checksum tool to compare source card and destination, and write a manifest. Keep three copies: camera, set drive, offline drive. “Copy completed” without a checksum is not a backup.

Checksum first, then three copies

After each card, play one file back; confirm name, duration and sound before formatting.

Limits

The media station is not an edit bay. Do not cut from the set drive; make copies and proxies first to avoid deletion and performance limits.

On set

Set up one table with a reader, SSD, laptop, and labels. Copy, verify the checksum, then name the files.

Do this

The media bay copies, verifies, names, and backs up on set; sorting later doubles the time.

  1. Set a table with card reader, SSD, laptop, and labels.
  2. Verify checksum after copying.
  3. Name by scene and shot.

Avoid

Do not take cards back to the studio to sort; unnamed on-set media doubles post time.

Judge

Three signals are observable on set:

  • every spec maps to one concrete shooting problem
  • weight, power and connections hold on a real rig
  • a 60-second test leaves one comparable number

Failures

These three moves erase the detail you just built:

  • specs without connections, power or weight
  • batteries, storage or body do not match after purchase
  • no 60-second test, so the problem arrives on the shoot

Extend

10-minute exercise: Run a 60-second test with the gear you already own, measuring only “Set a table with card reader, SSD, laptop,”. Record two numbers: what you need and what the gear actually gives.

3 checks

  • An on-set table has reader, SSD, laptop, and labels.
  • Every card copy gets a checksum verification.
  • Media is named by scene and shot and needs no later sorting.
