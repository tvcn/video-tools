Script Format: Make the Whole Crew Read It the Same Way

Script format is not for a literary prize; it helps camera, sound, and edit find information at a glance.

Format exists so the director, camera, sound and editor can find scene, action, dialogue and time on the same page. The slug line states location and time; action describes only what the camera can see; the character name sits above the line.

A script is a working document

Do not put unfilmable psychology in dialogue. Change “she is hesitant” into “she picks up the keys, then puts them back.”

Limits

A short film script does not need every shot, but every scene needs a want, an obstacle and a turn. Pretty format cannot save a scene with none of the three.

On set

Start each scene with interior or exterior, location, and time. Keep action blocks under four lines and capitalize a character name on first appearance. The sound team needs to know when the door opens.

Do this

  1. Open every scene with interior or exterior, location, and time.
  2. Keep action blocks under four lines; capitalize a character name on first appearance.
  3. Put door, phone, and footstep cues into the action so sound knows what to capture.

Avoid

Do not write a novel; if the crew cannot find scene numbers and sound cues, the set will miss them.

Judge

This page passes on three observable checks, not slogans:

  • 1. Every scene has interior or exterior, location, and time with continuous numbering.
  • 2. Action blocks stay under four lines and first character names are capitalized.
  • 3. Sound can mark at least three cues to record from the script.

Failures

Any one of these means stop and fix it before post:

  • 1. Check 1 is only staged (“Every scene has interior or exterior, location…”); another camera position or location exposes it.
  • 2. Check 2 is left to post or a verbal explanation (“Action blocks stay under four lines and first…”); nothing on set can be rechecked.
  • 3. Do not write a novel; if the crew cannot find scene numbers and sound cues, the set will miss them.

Extend

10-minute exercise: Write one 30-second scene with only “Open every scene with interior or exterior, location,” and “Keep action blocks under four lines; capitalize a”. Cut every explanation and ask one person to retell what the character wants.

Check

  • Every scene has interior or exterior, location, and time with continuous numbering.
  • Action blocks stay under four lines and first character names are capitalized.
  • Sound can mark at least three cues to record from the script.

Deep dive

About 6 minutes. The field note tells you how to write. This layer is about one page that lets five people start work at once, and which words to cut when you rewrite.

One page, five people using it at once

The director looks for action, the camera department for space, sound for lines, art for props, and the editor for scenes. A script is not literature; it is a work order five people can read at once.

A scene heading carries four facts: interior or exterior, location, time. Action describes only what the camera can see, and a character name is capitalized on first appearance. Keep each dialogue line under roughly thirty-five Chinese characters; long lines make actors gasp and subtitles overflow.

INT. KITCHEN — NIGHT
The kettle whistles. She kills the flame, picks up her phone, and deletes the message she just wrote.

Rewrite only three kinds of words

Cut explanatory adjectives, repeated names, and inner states the actor can play. Change “she angrily slams the door” to “she slams the door; it bounces back once.” Precise action gives the actor something to do.

Solve one class of problem per pass: one pass removes explanation, the next fixes pace, the next rewrites lines. Change three things at once and tomorrow you will not know who wrote which line.

Do not drop scene headings; the edit finds footage by them

Scene numbers are not for the director; they let script supervisors, editors, and post find footage. Start a new scene whenever time or place changes. Never replace a heading with “later.”

Separate day and night inside the same location. An editor looking for “kitchen night” does not want to read a page of prose.

Page count and shoot days

A page is roughly a minute on screen, but takes one to three hours on set depending on setups, cast, and weather. Three pages of dialogue are not automatically one day.

Schedule by pages times difficulty, not by scene count. Ten empty shots can take half a day; one crowd scene can take two.

Ten checks before you print

  • Scene heading names interior or exterior, place, and time
  • Action describes only what the camera can see
  • Capitalize a character name on first appearance
  • Keep each dialogue line under thirty-five characters
  • Give each scene one turn, not two
  • Delete explanatory adjectives
  • Turn inner states into playable action
  • Keep scene numbers continuous from first to last
  • Mark pickups and flashbacks separately
  • Leave a notes column for the script supervisor

If two of these ten fail, do not start a new scene. Make this page shootable; that is worth more than three more pages.
