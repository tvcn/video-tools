Documentary is not capturing reality; template, breakdown and ethics decide whose voice remains. One page of "Documentary Template: One Person, One Thing, One Change" solves one local problem; joining "Documentary Template: One Person, One Thing, One Change", "Documentary Breakdown: One Person, One Event, One Change" and "Documentary Ethics: Filming Vulnerable People" exposes the real failure: conditions are missing, too many variables move, and the result cannot be reproduced.

Problem

The problem is not a lack of methods; each step works alone, but together they fail because the condition was not written, too many variables moved and the result cannot be reproduced.

The order is condition, judgement, one variable and evidence. A step is complete only when the next person can repeat it.

Judgement

  • First gate in "Documentary Template: One Person, One Thing, One Change": The film has one person and one task in progress.
  • Second gate in "Documentary Breakdown: One Person, One Event, One Change": Interview does not open the piece; action comes first.
  • Third gate in "Documentary Ethics: Filming Vulnerable People": A visible change occurs, not only the subject saying so.

If one gate fails, return to its single page; do not hide an unsolved point inside a longer chain.

Method

  1. Write the condition first: turn "Choose one person and one task in progress." from "Documentary Template: One Person, One Thing, One Change" into three rows: material, environment, acceptance.
  2. Run one minimal action: follow "Documentary Template: One Person, One Thing, One Change" for 30 seconds and do not add the second page yet.
  3. Attach the second page: Shoot the task before the interview..
  4. Use the third page as a control: Wait for a visible change before fixing the structure..
  5. Change one variable at a time; write the other conditions down instead of remembering them.
  6. Film the failure too: put failure and success side by side to see which step cannot be skipped.
  7. Ask the next person to reproduce from the record; if they cannot, the record is not finished.

Field test

A reproducible test, not a client case: take 30 seconds of material, make version A using "The film has one person and one task in progress." from "Documentary Template: One Person, One Thing, One Change", then version B using "Interview does not open the piece; action comes first." from "Documentary Breakdown: One Person, One Event, One Change"; only one variable may differ. Put them side by side and record what breaks first in "Documentary Ethics: Filming Vulnerable People": condition, action or acceptance. If it works on the first try, add one real constraint and run it again.

Acceptance

  • The film has one person and one task in progress.
  • Interview does not open the piece; action comes first.
  • A visible change occurs, not only the subject saying so.
  • An action is happening in the first ten seconds.
  • Person, place, and task are clear within thirty seconds.
  • Want is filmable, not abstract.
  • Obstacle happens naturally, no fake conflict.
  • At least one complete attempt.
  • The same action after the change differs from the opening.
  • No summarizing narration at the end.

Alternatives

  • For a single-point problem in "Documentary Template: One Person, One Thing, One Change", go back to Documentary Template: One Person, One Thing, One Change; do not use the whole chain.
  • To compare two actions, read Documentary Breakdown: One Person, One Event, One Change and leave the third page alone.
  • For acceptance only, use Documentary Ethics: Filming Vulnerable People as a self-test sheet.
