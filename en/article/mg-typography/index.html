Motion Typography: Read, Then Move

Type must read at rest before it moves; reading while moving cuts comprehension in half.

The usual mistake is every letter flying, spinning and morphing while nobody finishes reading. Give the line enough hold time, then animate the entrance: under 0.3 seconds in, at least 1.5 seconds hold.

Type animation is readable before beautiful

One move per line: fade, rise or mask, not three at once.

Limits

Type is not decoration. Readability first: contrast, size, leading. Use display faces for titles, not long sentences.

MG typography: grid first, animation second

Type animation looks messy not because of the animation, but because there is no grid. Set baseline, tracking and safe area first, then move the type. Without a grid, more motion means more mess.

Define firstValuePurpose
Baseline gridDivide frame height into 8–12 rowsAlign multiple lines
TrackingChinese 0, English -2% to +2%Avoid loose or cramped lines
Safe area12% top and bottom on verticalPlatform UI does not cover text
WeightsTwo maximumClear hierarchy

Project-level checks

  1. Check the font license for commercial use. Display and body fonts are licensed separately; “downloadable” is not “usable.”
  2. Use two or three motions only: position, mask, weight change. Do not fly every letter.
  3. In mixed Chinese/English, set English at 80–90% of the Chinese size on the same baseline.
  4. Review at phone size; minimum type is 24px at 1080 width.

If the client asks for “all the type to move,” cut a five-second sample first. Too much motion eats the message.

On set

Make a still version that reads at phone width. Then animate six frames of entrance using position and opacity only; do not rotate, scale, and glow at once.

Do this

Motion typography must read at rest before it moves; reading while moving cuts speed in half.

  1. Make a static version and check it at phone width.
  2. Animate a six-frame entrance using only position and opacity.
  3. Do not add rotation, scale, and glow at once; protect the information.

Avoid

Do not use white flashes and pushes as universal transitions; unreadable type wastes the motion.

Judge

Three signals are observable on set:

  • the speed split between foreground, midground and background reads in one pan
  • a 0.5-second action still carries weight or anticipation
  • turn off any layer and the space still holds

Failures

These three moves erase the detail you just built:

  • more layers, same speed: the space stays flat
  • anticipation without follow-through: the weight is only half done
  • rendering before assets are locked: rework starts at the compositor

Extend

10-minute exercise: Draw three keys at 24 fps, change only “Animate a six-frame entrance using only position and”, and export two seconds. If the weight still does not read, add anticipation before adding blur.

3 checks

  • The static version reads at phone width and the longest line stays in frame.
  • The entrance moves only position and opacity, not rotation and scale together.
  • Muted playback still communicates the order of information.
