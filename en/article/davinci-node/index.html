DaVinci Nodes: Nodes Are Not Filters

Nodes are not filter stacks; one node does one job, and disabling it reveals its effect.

If the problem is camera white balance, exposure or lighting, more nodes only make it dirtier. Go back to the source before grading.

Basic node order

  • Balance then style: primary correction first, LUT and look later; reversing the order locks a cast into the LUT.
  • Local last: windows, tracking and local grades come after the global grade; local first breaks the overall relationship.
  • Cache and versions: more nodes cost performance; name key versions, do not rely on undo.

When not to stack nodes

On set

Build five nodes: exposure, white balance, contrast, look, and output. Toggle each one to see its job; do not stack twenty.

Do this

Nodes are not a filter stack; each node does one job, and turning it off reveals what it did.

  1. Build five nodes: exposure, white balance, contrast, look, output.
  2. Toggle each node and watch the change.
  3. Do not stack twenty and lose track of the cause.

Avoid

Do not stack twenty nodes; when something breaks, you cannot tell which to disable.

3 checks

  • Five nodes each do one job with clear names.
  • Toggling each shows its specific change.
  • No more than ten nodes, and problems map to one node.
