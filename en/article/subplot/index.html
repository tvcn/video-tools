Subplot: Only the One That Presses the Main Line

A subplot is not extra noise; it must squeeze the main line at one specific point.

A subplot is not a second couple to make the film rich. At some point it forces the hero to choose differently: because of this person they are late; because of this event they lose an exit.

A subplot must change one choice in the main line

Write two lines: what extra loss it creates, and whether it makes the ending harder or easier. If neither can be answered, cut it.

Limits

A short film has no time for two independent stories. A subplot is pressure on the main line, not a second center.

On set

When the subplot first appears, write what it owes the main line: a favor, a message, a lever. Every return adds pressure the main line cannot ignore.

Do this

A subplot is not extra heat; it must tighten the main line at a specific moment.

  1. On first appearance, state what it owes the main line: a favor, a message, leverage.
  2. Every appearance adds pressure the main line cannot ignore.
  3. If removing it leaves the main line unchanged, cut it.

Avoid

Do not add a subplot for busyness; if it does not press the main line, it is delay.

Judge

This page passes on three observable checks, not slogans:

  • 1. The subplot states its debt to the main line on first appearance.
  • 2. Each subplot appearance makes the main choice harder.
  • 3. Remove it and the main line loses pressure; it does not stay unchanged.

Failures

Any one of these means stop and fix it before post:

  • 1. Check 1 is only staged (“The subplot states its debt to the main line o…”); another camera position or location exposes it.
  • 2. Check 2 is left to post or a verbal explanation (“Each subplot appearance makes the main choice…”); nothing on set can be rechecked.
  • 3. Do not add a subplot for busyness; if it does not press the main line, it is delay.

Extend

10-minute exercise: Write one 30-second scene with only “On first appearance, state what it owes the” and “Every appearance adds pressure the main line cannot”. Cut every explanation and ask one person to retell what the character wants.

Check

  • The subplot states its debt to the main line on first appearance.
  • Each subplot appearance makes the main choice harder.
  • Remove it and the main line loses pressure; it does not stay unchanged.
