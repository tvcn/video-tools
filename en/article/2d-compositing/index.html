The giveaway is inconsistent line weight and color. Unify stroke width, anti-aliasing and value range before lighting; adjust each layer separately, not with a global filter.

2D compositing aligns line and color first

Check with a comparison frame: foreground and background blacks and whites must match; if not, it looks pasted on.

Limits

Compositing is not adding effects. No amount of effects fixes misaligned lines; align the base layers first.

2D compositing: fix edges, then color, then light

Compositing problems are usually order problems, not “not enough effect.” Color before edge work magnifies edge fringes. Light before edge work covers seams. The order is: clean plate → edge → color match → light → output.

StepCheckFailure signal
EdgeInspect at 1:1 pixelsWhite/black fringe, jaggies
ColorSkin and sky within one sceneForeground warmer or greener than background
LightLight direction matchesGlow passes through an occluder
OutputReview at each delivery sizeEdge vanishes small, seam shows large

Project-level checks

  1. Toggle every element and make a list. One missing shadow or contact shadow makes the layer float.
  2. Use the smallest edge setting, several light passes. One maxed-out pass eats detail.
  3. Match color on neutral gray first, then skin. Eyes alone drift on a colored background.
  4. Put the light pass on top but mask it behind foreground objects; otherwise light goes through walls.

Before delivery, ask someone else to watch ten seconds and answer only “what floats?” After staring for hours, you stop seeing seams.

On set

Use four layers: background, character, foreground, and light. Grade each separately and keep shadows off the character layer.

Do this

2D compositing separates background, character, foreground, and light; one flattened image means redrawing everything for one change.

  1. Use four layers: background, character, foreground, light effect.
  2. Grade each layer separately and keep shadows off the character layer.
  3. Composite position first, then light and shadow.

Avoid

Do not draw everything on one layer; one change forces a full redraw.

Judge

This page passes on three observable checks, not slogans:

  • 1. Background, character, foreground, and light are separate layers with clear structure.
  • 2. Shadows live on their own layer, not baked into the character.
  • 3. Changing an action moves only the character layer; background and light stay.

Failures

Any one of these means stop and fix it before post:

  • 1. Check 1 is only staged (“Background, character, foreground, and light a…”); another camera position or location exposes it.
  • 2. Check 2 is left to post or a verbal explanation (“Shadows live on their own layer, not baked int…”); nothing on set can be rechecked.
  • 3. Do not draw everything on one layer; one change forces a full redraw.

Extend

10-minute exercise: Draw three keys at 24 fps, change only “Grade each layer separately and keep shadows off”, and export two seconds. If the weight still does not read, add anticipation before adding blur.

Check

  • Background, character, foreground, and light are separate layers with clear structure.
  • Shadows live on their own layer, not baked into the character.
  • Changing an action moves only the character layer; background and light stay.
