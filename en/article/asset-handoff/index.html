Names, versions and paths must open on their own

A handoff must open on someone else's machine without you: relative texture paths, versioned caches, filenames with scene and date. Never use “final final” as a version.

Give each asset one line: who made it, what it is for, what it depends on, which version is current. The receiver should rebuild from the note without asking you.

Limits

A handoff is not zipping the entire project. Deliver only assets and caches for the current shot; archive old versions, or the package becomes too big to touch.

On set

Name assets project_asset_version and deliver to a shared drive with a dependency list and cache path. The next person runs it once before starting.

Do this

Asset handoff states naming, version, cache, and dependencies; miss one and the next person rebuilds.

  1. Name assets project_asset_version.
  2. Deliver to a shared drive with a dependency list and cache path.
  3. Have the next person open it once before taking over.

Avoid

Do not leave assets on a personal desktop; the next person cannot find them.

Judge

This page passes on three observable checks, not slogans:

  • 1. Asset names include project, asset, and version and sort cleanly.
  • 2. The shared drive holds a dependency list and cache path.
  • 3. The next person opens the asset from the list without asking the original artist.

Failures

Any one of these means stop and fix it before post:

  • 1. Check 1 is only staged (“Asset names include project, asset, and versio…”); another camera position or location exposes it.
  • 2. Check 2 is left to post or a verbal explanation (“The shared drive holds a dependency list and c…”); nothing on set can be rechecked.
  • 3. Do not leave assets on a personal desktop; the next person cannot find them.

Extend

10-minute exercise: Draw three keys at 24 fps, change only “Deliver to a shared drive with a dependency”, and export two seconds. If the weight still does not read, add anticipation before adding blur.

Check

  • Asset names include project, asset, and version and sort cleanly.
  • The shared drive holds a dependency list and cache path.
  • The next person opens the asset from the list without asking the original artist.
