Live Streaming Kit

Live kit: camera, capture card, wired network, hotspot backup, local recording; uptime first.

3 min read · Field noteTVCN EditorialEdited 2026-11

Network and audio before image

If the stream drops, viewers do not wait; if audio clips, a sharp image does not save it. The order is network, audio, backup recording, cameras, lighting.

  • Minimum: one camera, one capture card, one laptop, wired network, one lav or console feed; run a 15-minute private test first.
  • Working: a second network path (hotspot or router), independent audio, backup recording, headphones and a waveform display; you can see drops and clipping.
  • Insured: hardware encoder, UPS, second camera and independent backup recorder; a failed primary path can be switched.

Pre-broadcast test

  1. Push a private stream for 15 minutes at the real bitrate; log dropped frames, latency and upload variation.
  2. Have the host speak normally; confirm both the live feed and backup recording do not clip or drift.
  3. Unplug the primary network, confirm the backup takes over, then plug it back and confirm no duplicate stream.

Do not gamble on wireless

Use Ethernet whenever possible; wireless is backup only. Do not discover insufficient upload at showtime, and do not put backup recording on the same machine without independent power.

On set

Camera, capture card, wired network, hotspot backup, and local recording. Rehearse one network drop.

Avoid

Do not rely on venue Wi-Fi alone; one drop erases the stream.

3 checks

  • The stream runs wired and the backup hotspot is speed-tested.
  • A complete local recording exists alongside the stream.
  • The disconnect drill logs switchover and recovers within ten seconds.
