Buying Project Storage: Speed, Capacity, and Backup

Storage is not “bigger is better.” It is “the shoot does not stop, the offload does not lose data, and the project is findable later.” Calculate a real shoot day before buying.

First decision: which link is missing

Calculate a shoot day: camera bitrate × hours × cameras × copies. 4K 10-bit 422 is roughly 100–200 GB/hour; three cameras for eight hours is 2.4–4.8 TB before copies. Size for the worst day, not “enough this year.”

Fits:

  • Multicam/high-bitrate projects
  • On-set offload and backup
  • Long-term project archive

Does not fit:

  • Single-camera 1080p lightweight work
  • One drive for everything
  • Using NAS as an on-set drive

Test conditions: how to check before buying

This is not a cross-brand shootout and it does not settle brands. These three checks are a field protocol you can repeat in a shop or with a loaner; cells without measurements say “not measured” rather than inventing numbers. Record body, firmware, room temperature, recording format and card; change one condition and the result can change.

#How to testStatus
1Copy 50 GB from the card; log sustained write curveNot measured
2Write again at 10% free space; watch for dropNot measured
3Unplug/replug; measure rebuild and mount timeNot measured

Pass line: Sustained write above your bitrate, no near-full drop, and a rebuild you can wait for.

Sources: editorial standards · test protocols; manufacturer specs come from public spec sheets, and untested values are not turned into numbers.

If one of the three can only be answered by “I heard” or a spec sheet, do not order yet. Write the condition into your shoot plan, then decide whether it changes your kit.

Test protocol: reproducible, no invented scores

Record 30 minutes at the project bitrate or copy a 100GB file and log real write speed and throttling. Do not trust the interface label: USB-C is not Thunderbolt, and a spinning drive cannot saturate 10GbE.

Alternatives and upgrades: do not add money on the wrong axis

  • Two ordinary SSDs for double backup
  • Rent an on-set DIT
  • Existing drives + cloud backup

Buying steps: bring footage, not spec sheets

Run these in order before paying. If one fails, do not tell yourself post will fix it.

  1. Calculate worst shoot day
  2. Record 30 min at project bitrate
  3. Time a 100GB copy
  4. Confirm interface and power
  5. Check warranty/data recovery

Decision tree: working disk, backup, archive

Most people treat storage as one drive, then lose the working disk with no backup or keep an archive too slow to use. Split three layers: working fast, backup independent, archive readable in ten years.

  1. Working: SSD/RAID 0, capacity covers the current project, speed at least twice the project bitrate.
  2. Backup: independent HDD/NAS, at least one offline copy.
  3. Archive: LTO or cold drive, verifiable and restorable.
  4. Name, checksum and retention for every layer.

Test scope: sustained write and restore drill

Write for thirty minutes and log speed, temperature and dropout; restore a random file from backup and time it; compare checksums. Not measured: lab IOPS or long-term aging.

Continue: storage and backup hub

Cards first, then arrays and backup.

  • Buying cards: VPG, sustained write, heat
  • Buying NAS/RAID: throughput, rebuild, noise
  • SSD RAID: editing array
  • 3-2-1 backup: finish it today
  • Restore drill: pick one random file
  • Media management: back up today, name for search
  • Media cart: offload and naming on set
  • LTO archive: long-term cold storage
  • ProRes export: archive and delivery
  • Proxy creation: edit without stutter

Buying order: rent before buying

Borrow a card/SSD for one real project; log sustained write and offload time before choosing capacity and redundancy.

  1. Rent the target body and a common lens once; shoot a real project.
  2. Confirm mount, adapter, autofocus and power.
  3. Total the cards, batteries, monitor, storage and repair.
  4. Keep 10% for surprises and consumables.
  5. Buy the second lens after the first delivery.

One line for the set

The working disk may fail; the backup must not fail with it. That is the whole point of three layers.

Regional note for US / UK / EU readers

This English page keeps mainland-China examples where they are part of the method. Read platform names as examples, not as the only market: Douyin ↔ TikTok/Reels, Bilibili ↔ YouTube, Xiaohongshu ↔ Instagram/Pinterest; RMB figures are not converted here. Voltage, plug, warranty, import duty and radio certification differ by market; check the local spec sheet before ordering gear or batteries.

3 checks

  • V90 or CFexpress runtime is calculated at the highest bitrate.
  • The SSD is TLC with DRAM and at least twice the footage size.
  • Two different-brand drives are used, one off-site.
