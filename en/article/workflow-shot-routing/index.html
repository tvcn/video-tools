Shot routing: which model for which shot

One project should not use one model. Route by shot type: face, hands, motion, product, text and long take, each with primary and backup, then rank by cost per usable second.

Fit and no-fit / 适用与不适用

  • Multi-shot projects where one model fails on a shot class.
  • Producers allocating models within budget.
  • Not for: a single 5s shot with no comparison budget.

Do this / 怎么做

  1. List six classes: face, hands, motion, product, text, long take.
  2. Pick two candidates per class; run three takes.
  3. Log failure rate, not only the best take.
  4. Write routing as primary/backup/banned.
  5. Cost by project weight, not overall rank.

Avoid / 别踩

  • One model for the whole film; one class never passes.
  • Only the best take; no failure rate in routing.
  • Forcing text/screens from the model; typos cannot be fixed.

Go deeper / 继续往下

Routing admits models have weaknesses. One is strong on faces and weak on hands; another stable on products and fake on motion. Split into six classes and test each to bring failure rate down.

Routing needs bans: shots that must never use a model. Bans matter more than recommendations; they stop the team returning to a known failure under deadline.

Checks / 验收

  • All six classes have primary/backup/banned.
  • At least three runs per candidate with a failure rate.
  • Text/screens are not forced through generation.
  • Routing ranks by project weight, not leaderboard.
