Negative Prompt: Remove Before You Add

Remove what ruins the frame first: flicker, extra fingers, garbled text, face morphing.

Negative prompts list visible things to avoid

A negative prompt is not a wish list. Write “extra fingers, text, watermark, plastic skin, over-sharpening,” not “ugly, cheap, unrealistic”; the model cannot execute the latter.

Add two or three negatives per pass and compare; too many suppress legitimate detail, leaving a clean but empty image.

Limits

Negatives cannot fix structure. If proportions are wrong, change the positive description and reference; negatives subtract, not rebuild.

On set

List four categories: flicker, extra fingers, garbled text, warped faces. One negative term per category; do not stack fifty.

Do this

Negative prompts remove what breaks the image first: flicker, extra fingers, garbled text, face warping.

  1. List four classes: flicker, fingers, text, face.
  2. Write one negative term per class, not fifty.
  3. Run three times and confirm the term actually reduces that problem.

Avoid

Do not stack a long negative list; conflicting constraints make the model less stable.

3 checks

  • Negative terms cover four problem classes and each maps to a visible error.
  • The problem visibly decreases across three outputs, not just in your head.
  • Remove one term and the problem returns, proving it worked.
