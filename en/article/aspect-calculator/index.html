Formula and safe area

Aspect ratio = width ÷ height. Cropping 16:9 to 9:16 keeps width = original height × 9 ÷ 16; a 3840×2160 frame becomes 1215×2160, losing about 1312 pixels on each side.

Three common conversions

  • 16:9 → 1:1: keep 2160×2160, lose 840 pixels each side.
  • 16:9 → 4:5: keep 1728×2160, lose 1056 each side.
  • When shooting 9:16, keep the subject inside the central 1080-wide safe area.

Limits

A crop is not a recomposition; action and subtitles must stay inside the safe area. Platforms crop again, so check the platform preview before delivery.

On set

4K 16:9 cropped to 9:16 leaves about 1215×2160. Confirm the pixels are enough and redraw safe areas per platform.

Do this

An aspect-ratio calculator first computes effective pixels after crop, then the safe area; vertical is not just cropping the sides.

  1. 4K 16:9 cropped to 9:16 leaves about 1215×2160.
  2. Confirm the pixel count is enough.
  3. Redraw the safe area for the platform.

Avoid

Do not crop landscape into vertical blindly; effective pixels halve and close-ups soften.

Boundary

It does not replace an on-set reading. The number is a starting point; the monitor, scope or actual recording decides.

Alternative

If “4K 16:9 cropped to 9:16 leaves about 1215×2160.” is not the main problem, start with the basic move behind “Confirm the pixel count is enough.”. Upgrade only after both hold.

60-second test

Run a 60-second test with the gear you own, focused on “4K 16:9 cropped to 9:16 leaves about 1215×2160.”, and record one number. If the number does not change, do not add budget.

3 checks

  • Cropped effective pixels are numeric, about 1215×2160.
  • Pixels meet delivery needs without upscaling.
  • The safe area is redrawn for vertical platforms, not reused from landscape.
