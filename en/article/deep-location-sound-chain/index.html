Location sound is not one microphone; it is mic, wireless, recorder, backup and log. One page of &quot;Field Recorder: 32-Bit Is Not Magic&quot; solves one local problem; joining &quot;Field Recorder: 32-Bit Is Not Magic&quot;, &quot;Shotgun Mic: Point It, Get Close&quot; and &quot;Wireless Lav: Frequency and Backup&quot; exposes the real failure: conditions are missing, too many variables move, and the result cannot be reproduced.

Problem

The problem is not a lack of methods; each step works alone, but together they fail because the condition was not written, too many variables moved and the result cannot be reproduced.

The order is condition, judgement, one variable and evidence. A step is complete only when the next person can repeat it.

Judgement

  • First gate in "Field Recorder: 32-Bit Is Not Magic": Quiet dialogue peaks near -12 dB with audible noise floor.
  • Second gate in "Shotgun Mic: Point It, Get Close": Deliberate clipping is recovered to intelligibility in 32-bit.
  • Third gate in "Wireless Lav: Frequency and Backup": A wind test proves float cannot rescue wind-eaten dialogue.

If one gate fails, return to its single page; do not hide an unsolved point inside a longer chain.

Method

  1. Write the condition first: turn "Record quiet dialogue with peaks at -12 dB." from "Field Recorder: 32-Bit Is Not Magic" into three rows: material, environment, acceptance.
  2. Run one minimal action: follow "Field Recorder: 32-Bit Is Not Magic" for 30 seconds and do not add the second page yet.
  3. Attach the second page: Deliberately clip once and see whether 32-bit recovers it..
  4. Use the third page as a control: Test wind and confirm float cannot rescue it; do not treat it as insurance..
  5. Change one variable at a time; write the other conditions down instead of remembering them.
  6. Film the failure too: put failure and success side by side to see which step cannot be skipped.
  7. Ask the next person to reproduce from the record; if they cannot, the record is not finished.

Field test

A reproducible test, not a client case: take 30 seconds of material, make version A using "Quiet dialogue peaks near -12 dB with audible noise floor." from "Field Recorder: 32-Bit Is Not Magic", then version B using "Deliberate clipping is recovered to intelligibility in 32-bit." from "Shotgun Mic: Point It, Get Close"; only one variable may differ. Put them side by side and record what breaks first in "Wireless Lav: Frequency and Backup": condition, action or acceptance. If it works on the first try, add one real constraint and run it again.

Acceptance

  • Quiet dialogue peaks near -12 dB with audible noise floor.
  • Deliberate clipping is recovered to intelligibility in 32-bit.
  • A wind test proves float cannot rescue wind-eaten dialogue.
  • One line is recorded at one, two, and three meters.
  • Playback reveals dialogue buried past two meters.
  • Shots beyond two meters have a lav or boom alternative.
  • A two-minute scan logs a clean frequency.
  • The transmitter sits at the lower back with no visible cable.
  • A 32-bit backup track exists and works independently.
  • The condition from Field Recorder: 32-Bit Is Not Magic fits on one line and can be repeated by someone else.

Alternatives

  • For a single-point problem in "Field Recorder: 32-Bit Is Not Magic", go back to Field Recorder: 32-Bit Is Not Magic; do not use the whole chain.
  • To compare two actions, read Shotgun Mic: Point It, Get Close and leave the third page alone.
  • For acceptance only, use Wireless Lav: Frequency and Backup as a self-test sheet.
