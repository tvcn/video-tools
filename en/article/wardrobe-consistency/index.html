Wardrobe Consistency: One Outfit, One Description

Wardrobe consistency needs a fixed description and reference, not the words "same person."

Wardrobe continuity uses numbers and photos

Number each costume and photograph front, back and detail; check before each scene. Record collar, cuffs, buttons and stain positions, not just color.

Shoot dirt, rain and changes in script order; once the state changes, going back is expensive.

Limits

Continuity is not identical every frame. The audience will not count buttons but will notice “that is a different jacket.” Protect visible state.

Wardrobe consistency: build a character sheet before generating shots

AI wardrobe drift is usually not a model failure; the reference is not specific enough. “White shirt, jeans” produces a hundred white shirts. A character sheet must specify collar, buttons, fabric, wear and color values.

ItemSpecifyPurpose
SilhouetteLoose/fitted, shoulder, lengthHold the outline
DetailCollar, pockets, button countPrevent a new design each generation
FabricWeave, weight, sheenControl texture
ColorHEX or swatch numberMatch across shots

Project-level checks

  1. Make front, side and back views of the same outfit. One front view is not enough.
  2. Every shot carries the same character sheet and reference image. Do not change reference between shots.
  3. Check collar, cuff, waistline and shoes; these drift first.
  4. If the model supports a seed, a fixed seed only solves part. Garment structure still needs references.

Before delivery, grab one frame from each shot and build a contact sheet. If you can see a wardrobe change at a glance, redo that frame.

On set

Describe color, fabric, collar, sleeves, and pattern. Crop the reference to the garment only; a face in the reference leaks into the model.

Do this

Wardrobe consistency comes from a fixed description and a clothing reference, not “same person.”

  1. Describe five traits: color, material, collar, sleeves, pattern.
  2. Crop the reference to clothes only, no face, so the model does not blend identity.
  3. Compare collar and pattern per shot; if they drift, fix the description.

Avoid

Do not use a face reference to lock clothes; the model blends face and garment.

3 checks

  • The wardrobe description covers color, material, collar, sleeves, and pattern.
  • The reference shows clothes only with no face or background distraction.
  • Collar and pattern stay consistent; the garment does not change between shots.
