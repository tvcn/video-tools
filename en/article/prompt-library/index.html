Prompt library by shot type

Twenty reusable prompts grouped by face, hands, motion, product, text and long take. Change only subject/action/light; no empty words like “cinematic.”

Fit and no-fit / 适用与不适用

  • Creators starting from zero every prompt, with unstable results.
  • Teams needing one prompt format for handoff.
  • Not for: people wanting one magic prompt.

Do this / 怎么做

  1. Pick shot type, then template.
  2. Change subject only: age/wardrobe/material.
  3. Change action: one start, one end.
  4. Change light: direction/hardness/temperature.
  5. Keep bans: no text/logo/multiple heroes.

Avoid / 别踩

  • Five actions in one prompt; the model averages.
  • Using “premium/cinematic”; not actionable.
  • Generating slogans; typos.

Go deeper / 继续往下

A prompt library reduces variables, not adds adjectives. A good prompt is a shot card: subject, action, light, camera, duration, bans. More adjectives average out.

Twenty templates are not secrets but twenty combinations of six shot classes. Learn to change one variable, not memorize sentences. Log each change and result beside the template; in three months it is your library.

Checks / 验收

  • Each prompt has subject/action/light/camera/bans.
  • One variable per iteration.
  • Text/logo not generated.
  • Template lets another person reproduce.
