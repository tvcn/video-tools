Buying Used Gear: Shutter, Sensor, and Service

Used is not “cheap”; it is risk priced in. Check shutter, sensor, ports, and service history before negotiating. Without a test shoot and return terms, walk away.

First decision: which link is missing

Check known faults and repair cost: some bodies have shutter/mainboard/slot issues. Used is worth the risk below 60% of new; below 50% usually hides something. For lenses, check fungus, scratches, and AF motor; for bodies, shutter, sensor, ports, and slots.

Fits:

  • Limited budget, previous flagship
  • Test shoot/in-person OK
  • Repair channel available

Does not fit:

  • Need new warranty
  • No test/return
  • Risky model/grey import

Test protocol: reproducible, no invented scores

Meet with a laptop and card: shoot a white wall for dead pixels, 30-second exposure for hot noise, video for rolling shutter/AF, test HDMI/USB/slots, and check shutter count and serial.

Price bands: total cost of ownership first

Look beyond the sticker: cards, batteries, adapters, gimbal, stands, software subscriptions, and repair. Bands describe the minimum kit for a real project type, not toy pricing.

Alternatives and upgrades: do not add money on the wrong axis

  • Rent a month first
  • Buy official refurbished
  • New entry instead of old flagship

Buying steps: bring footage, not spec sheets

Run these in order before paying. If one fails, do not tell yourself post will fix it.

  1. Check known faults/repair cost
  2. White wall/long exposure
  3. Test each port/slot
  4. Check shutter/serial
  5. Write return/warranty terms

Check

  • Shutter under 50% life.
  • Sensor has no dead pixels/scratches/fungus.
  • All ports/slots work.
  • Serial is checkable.
  • Price below 60–75% of new.
  • Test/return terms exist.

Regional note for US / UK / EU readers

This English page keeps mainland-China examples where they are part of the method. Read platform names as examples, not as the only market: Douyin ↔ TikTok/Reels, Bilibili ↔ YouTube, Xiaohongshu ↔ Instagram/Pinterest; RMB figures are not converted here. Voltage, plug, warranty, import duty and radio certification differ by market; check the local spec sheet before ordering gear or batteries.
