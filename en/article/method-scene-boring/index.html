A Scene Has No Change

If a scene changes nothing, cut it or let someone gain or lose something.

Write three sentences: what they want at the start, what blocks them, what they do by the end. If the third sentence does not exist, the scene has no event. Do not rescue it with more angles and music.

Does the scene change anything?

  • Goal: what does the character want in this scene? If you cannot say it, the scene is a transition.
  • Obstacle: who or what blocks them? The obstacle must be present, not only in dialogue.
  • Turn: by the end, what the character knows, where they are or who they are to someone must change. If nothing changes, cut or merge it.

When not to add a scene

If the scene changes neither character nor information, deleting it is stronger than adding action. In a short film, every scene carries one turn.

On set

Make someone gain or lose something. If nothing changes, cut the scene.

Do this

If a scene does not change, cut it, or let someone gain or lose something.

  1. Write the state at the start and the state at the end; they must differ.
  2. Take an object away, close a door, or say the line that changes the relationship.
  3. If the state is unchanged, cut the scene and fold its information into the next one.

Avoid

Do not keep a static scene alive with “mood.”

Boundary

This page only covers “A Scene Has No Change”; it does not replace You Are Shooting Alone, The Opening Is Too Slow, 16mm: Cinema Left the Theater. When the problem belongs to one of those pages, use that page instead of adding more parameters here.

Alternative

If “Write the state at the start and the state at the end; they must differ” is not the main problem, start with “Take an object away, close a door, or say the line that changes the relationship”; only upgrade after both hold.

60-second test

Run one 60-second test against check 1: The start and end states are written down and they differ. If check 2 (An object, a door, or a line changes the relationship) does not change, do not add gear or budget.

Check

  • The start and end states are written down and they differ.
  • An object, a door, or a line changes the relationship.
  • If the state did not change, the scene is cut or merged.
