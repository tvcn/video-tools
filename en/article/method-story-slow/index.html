The Opening Is Too Slow

Cut the first thirty seconds and start where someone is already acting; context can wait.

What happens in the first eight seconds?

  • Only atmosphere: the opening is a wide shot, titles and music, and nobody wants anything yet. Move the first person with a goal earlier.
  • Only explanation: narration explains backstory while nothing happens. Delete it and replace it with a visible action.
  • Late conflict: the character meets the obstacle after 30 seconds. Put the obstacle in the first shot.

An eight-second test

Show only the first eight seconds to someone who has not seen it, muted, then ask: who did you see, what did they want, what blocked them? If they cannot answer, the opening has not started. Do not use music or titles to supply the answer.

When not to speed up

If the character is not established, speeding up only makes it less clear. Add an action or one informative line before discussing pace.

On set

Cut the first thirty seconds and start where the character is already doing something. Add context later.

Do this

A slow opening: cut the first thirty seconds and start where the character is already doing something. Backstory can come later.

  1. Find the first shot where the character must act, and start there.
  2. Split the backstory into two or three beats and hide them inside later actions.
  3. Keep only one question and one action in the first thirty seconds; no world-building.

Avoid

Do not narrate the backstory in voice-over or titles; the audience came to watch action.

3 checks

  • The film starts where the character is already doing something.
  • The first thirty seconds hold one question and one action.
  • Backstory is split into two or three beats inside later actions.
