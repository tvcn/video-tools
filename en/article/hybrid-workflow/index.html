Hybrid Workflow: Lock Live Action First

Lock live action before generating missing shots. Generate first and the light will never match.

Lock live action, then generate the controllable part

The anchor of a hybrid workflow is live action: shoot the actor, light, motion and space first, then use generation only where live action cannot go—set extension, dangerous action or a landmark that does not exist.

Log the source, prompt, version and rights for every generated shot. In the edit you must be able to say which second is live and which is generated.

Limits

Do not replace an entire performance with generation. An audience accepts an impossible background more easily than a hero without gravity. Shots without a live anchor go back to set.

On set

Shoot the live-action master first and log camera, lens, and light position. Prompt the generated shots from those values, then match grain and grade.

Do this

Live-action plus AI locks the plate first, then generates missing shots; generating before the shoot guarantees a light mismatch.

  1. Shoot the main plate and record camera, lens, and light positions.
  2. Generate missing shots from those parameters.
  3. Unify grain, grade, and sound, then check the seam.

Avoid

Do not generate before the shoot; the light will not match.

3 checks

  • The plate has complete camera, lens, and light notes.
  • Generated shots use those parameters, not a separate setup.
  • At the seam, light direction, grain, and motion match and the boundary disappears.
