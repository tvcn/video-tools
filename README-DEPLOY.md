# TVCN Pages build

This folder is generated by `build/make-release.py` from `v2/prototype` and `v2/static`.

- `index.html` is the static home; `/app/` is the interactive entry.
- `assets/` carries photos, diagrams, audio and downloadable templates.
- `manifest.webmanifest` and `sw.js` enable install/offline after an HTTP(S) deploy.
- `404.html` is the GitHub Pages fallback.
- `article/<id>/` and `en/article/<id>/` are static article pages (519 pairs, 1038 pages).
- `sitemap.xml` lists 1114 same-host URLs; the AI subsite ships a 184-URL `sitemap-ai.xml`; the other seven subsites keep a two-URL sitemap (`/` and `/en/`).
- Keep `robots.txt` and `.nojekyll`.

Before uploading, add `CNAME` (`tvcn.org`) only after DNS is pointed at Pages.
Search Console, analytics, newsletter and commercial integrations are intentionally not part of this local build.
