# Experimental Structure: Rules Before Effects

> Set rules first: locked camera, repeated action, one color. Clear rules make stronger effects.

## Segment table

| Segment | Duration | Image | Sound | Viewer expectation |
| --- | --- | --- | --- | --- |
| Rule | 0–15s | Locked camera, one repeated action | Location sound, no score | “I know what this is” |
| Repeat 1 | 15–30s | Same action, slight change | Same ambience | “It will happen again” |
| Repeat 2 | 30–45s | Same action, longer hold | One foreign sound | “Something is off” |
| Break | 45–55s | Action interrupted or reversed | Sound cuts, then returns | “The rule failed” |
| Aftermath | 55–60s | Return to the rule, incomplete | Ambience only | “What just happened” |
| End card | 2s | Black or a still object | Silence | Space |

Times are ceilings. Get one usable shot per segment before adding more.
