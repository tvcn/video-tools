多镜头连续性：角色、场景、服装

多镜头连续性不是“同一个角色出现三次”，而是脸、服装、道具、光向、运动方向在切换时都不跳。先锁三样，再拍第四镜。

适用与不适用 / Fit and no-fit

  • 短剧、广告、产品故事需要 3 个以上镜头。
    Short drama, ads or product stories with three-plus shots.
  • 角色/服装/场景在镜头间漂移的项目。
    Projects where character, wardrobe or set drifts between shots.
  • 不适用：单镜头或纯空镜项目。
    Not for: single-shot or pure b-roll projects.

怎么做 / Do this

  1. 先做角色卡：正/侧/全身 + 固定描述。
    Make a character sheet: front/profile/full body + locked description.
  2. 再做场景卡：一张主图 + 光向 + 色温。
    Make a set card: hero image + light direction + temperature.
  3. 服装写成可复用段落，不每次重写。
    Write wardrobe as a reusable paragraph, not fresh each time.
  4. 每个镜头标运动方向：左→右/右→左。
    Tag motion direction per shot: L→R or R→L.
  5. 剪辑时先看方向/光向，再看表演。
    In the edit, check direction/light before performance.

别踩 / Avoid

  • 每个镜头重写角色描述；第三次一定变。
    Rewriting the character each shot; it changes by shot three.
  • 场景光向不一致；观众觉得“假”但说不出。
    Inconsistent light direction; viewers feel fake without naming it.
  • A 镜左→右，B 镜右→左；剪辑像跳轴。
    A moves L→R, B moves R→L; the cut jumps the axis.

继续往下 / Go deeper

连续性的第一层是“观众不觉得跳”，第二层才是“完全一样”。脸有 90% 像就够，但光向、运动方向、服装颜色必须 100% 一致；前者观众容忍，后者一眼出戏。

用一张“连续性表”管理：镜号、角色、服装、场景、光向、运动方向、道具。每加一个镜头，填一行；填不出来，说明这个镜头还没准备好。

验收 / Checks

  • 角色卡/场景卡/服装描述三个镜头共用。
    Character/set/wardrobe shared across three shots.
  • 每个镜头标了运动方向。
    Every shot has a motion direction.
  • 光向在剪辑里能连成一条线。
    Light direction connects across the cut.
  • 关掉声音看一遍，故事仍清楚。
    Watch without sound; story still reads.
