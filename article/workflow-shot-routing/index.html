镜头路由：哪个镜头用哪个模型

一个项目不该只用一个模型。按镜头类型路由：人脸/手/运动/产品/文字/长镜头，各自选主模型和备模型，再按可用秒成本排序。

适用与不适用 / Fit and no-fit

  • 多镜头项目，单一模型总在某类镜头上翻车。
    Multi-shot projects where one model fails on a shot class.
  • 制片需要在预算内分配不同模型。
    Producers allocating models within budget.
  • 不适用：单个 5 秒镜头、没有比较预算。
    Not for: a single 5s shot with no comparison budget.

怎么做 / Do this

  1. 列六类镜头：人脸、手、运动、产品、文字、长镜头。
    List six classes: face, hands, motion, product, text, long take.
  2. 每类选 2 个候选，跑同题 3 次。
    Pick two candidates per class; run three takes.
  3. 记录失败率，不只看最好一条。
    Log failure rate, not only the best take.
  4. 按“主/备/禁用”写路由表。
    Write routing as primary/backup/banned.
  5. 按项目权重算成本，不按总排名。
    Cost by project weight, not overall rank.

别踩 / Avoid

  • 全片一个模型；某类镜头永远过不了。
    One model for the whole film; one class never passes.
  • 只看最好一条；路由表没有失败率。
    Only the best take; no failure rate in routing.
  • 文字/屏幕硬让模型生成；错字无法修。
    Forcing text/screens from the model; typos cannot be fixed.

继续往下 / Go deeper

镜头路由的核心是“承认模型有短板”。一个模型可能人脸很强、手很弱；另一个产品很稳、运动很假。把镜头拆成六类，分别测试，才能把每个镜头的失败率压到可接受。

路由表要写“禁用”：哪些镜头绝不能用某个模型。禁用比推荐更重要，因为它防止团队在紧急时又回到那个已知会崩的模型。

验收 / Checks

  • 六类镜头都有主/备/禁用。
    All six classes have primary/backup/banned.
  • 每个候选至少 3 次同题，失败率有数字。
    At least three runs per candidate with a failure rate.
  • 文字/屏幕不交给生成模型硬做。
    Text/screens are not forced through generation.
  • 路由表按项目权重排序，不是排行榜。
    Routing ranks by project weight, not leaderboard.
