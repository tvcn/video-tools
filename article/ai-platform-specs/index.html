适用与不适用 / Fit and no-fit

  • 一条片要分发多个平台、需要统一规格。
    One piece distributed to multiple platforms.
  • 广告/电商/独立站的交付规格。
    Ad/ecommerce/DTC delivery specs.
  • 不适用：广播/影院母版（按台标/客户 spec）。
    Not for: broadcast/cinema masters (follow broadcaster/client spec).

怎么做 / Do this

  1. 先定主版：9:16 或 16:9。
    Pick master: 9:16 or 16:9.
  2. 再做平台版：比例/时长/码率。
    Make platform versions: ratio/duration/bitrate.
  3. 字幕按平台安全区重排。
    Re-layout subtitles per safe area.
  4. 响度统一 -14 LUFS 左右。
    Unify loudness around -14 LUFS.
  5. 每版上传测试，不只看本地播放。
    Upload-test each version, not only local playback.

别踩 / Avoid

  • 一版通投；平台 UI 遮字幕/主体。
    One cut for all; UI covers subtitles/subject.
  • 码率太低；上传后糊。
    Too low bitrate; blurry after upload.
  • 响度太高；平台压缩后失真。
    Too loud; platform compression distorts.

继续往下 / Go deeper

平台规格是“推荐口径”，不是永久法律。平台会改 UI、改时长、改码率；本页标注 2026-11，发布前再看官方创作者页。不要拿三年前的规格表做今天的交付。

多平台最稳的做法是“主版 + 派生版”：主版保留最大信息，派生版按比例/安全区/时长重排。不要用同一个文件改文件名就上传；观众看到的是被裁的主体和被遮的字幕。

验收 / Checks

  • 主版+平台版分开，比例正确。
    Master and platform versions separated, ratio correct.
  • 字幕在底部 15% 安全区。
    Subtitles in bottom 15% safe.
  • 响度 -14 LUFS 左右。
    Loudness around -14 LUFS.
  • 每版真实上传测试。
    Each version upload-tested.
