交付规格：平台、广播、广告、字幕、安全区

交付不是“导出一个 MP4”。平台版、广播版、广告版各有比例、码率、响度、字幕安全区和文件命名；先定交付，再生成。

适用与不适用 / Fit and no-fit

  • 需要同时交平台版/广播版/广告版的制片。
    Producers delivering platform/broadcast/ad versions.
  • 需要字幕安全区/响度/命名规范的团队。
    Teams needing subtitle safe area/loudness/naming.
  • 不适用：只发一条朋友圈的个人。
    Not for: one personal social post.

怎么做 / Do this

  1. 先列交付表：比例/分辨率/帧率/码率。
    List delivery: ratio/resolution/frame rate/bitrate.
  2. 音频响度：平台 -14 至 -12 LUFS；广播按台标。
    Loudness: platform -14 to -12 LUFS; broadcast per spec.
  3. 字幕安全区：底部 10–15%，不贴边。
    Subtitle safe: bottom 10–15%, not edge.
  4. 文件命名：项目_版本_比例_语言_日期。
    Naming: project_version_ratio_language_date.
  5. 每版单独验收：手机/电视/平台上传。
    Check each version: phone/TV/platform upload.

别踩 / Avoid

  • 只交一个 MP4；平台/客户要三版。
    One MP4 only; platform/client needs three.
  • 响度超标；平台二次压缩后对白糊。
    Loudness over spec; platform recompression muddies dialogue.
  • 字幕贴边；电视/手机 UI 遮住。
    Subtitles at edge; TV/phone UI covers.

继续往下 / Go deeper

交付规格要写在生成之前，不是剪辑之后。9:16 的主体位置、16:9 的环境、1:1 的居中，构图完全不同；生成后再裁，主体不是被切就是太小。

响度和字幕是最容易返工的两项。平台会二次压缩，-14 至 -12 LUFS 更安全；字幕底部 10–15% 是安全区，贴边会被 UI 遮。把这两项写进交付表，后期少改三轮。

验收 / Checks

  • 交付表列全比例/分辨率/帧率/码率/响度。
    Delivery table lists ratio/resolution/rate/bitrate/loudness.
  • 每版字幕在安全区。
    Subtitles in safe area for each version.
  • 文件命名可追溯版本/日期/语言。
    Naming traces version/date/language.
  • 平台/电视/手机各验收一次。
    Checked on platform/TV/phone.
