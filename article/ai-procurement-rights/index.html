AI 影像 / 专业流程

采购、合同、数据与商用

买 AI 视频服务，合同要写清六件事：模型版本、输出权利、数据使用、地区、停运/迁移、责任上限。别只看“商用授权”四个字。

适用与不适用 / Fit and no-fit

  • 采购 API/订阅/本地部署的团队。
    Teams buying API, subscription or self-hosted models.
  • 需要把 AI 输出用于广告/客户交付的制片。
    Producers using AI output in ads/client delivery.
  • 不适用：个人非商用试用。
    Not for: personal, non-commercial trials.

怎么做 / Do this

  1. 列使用场景：广告/影视/电商/内部。
    List use cases: ads/film/ecommerce/internal.
  2. 核对输出权利：商用/修改/转售/独家。
    Check output rights: commercial/modify/resell/exclusive.
  3. 核对数据：输入是否训练/留存/跨境。
    Check data: training/retention/cross-border.
  4. 写停运/迁移：通知期/导出/替代。
    Write sunset/migration: notice/export/replacement.
  5. 写责任上限/赔偿/终止。
    Write liability cap/indemnity/termination.

别踩 / Avoid

  • 只看“可商用”；没写修改/转售/独家。
    Only “commercial”; no modify/resell/exclusive.
  • 忽略数据训练条款；客户素材进模型。
    Ignoring training terms; client assets enter the model.
  • 没有停运条款；模型下线项目停摆。
    No sunset clause; model shutdown stops the project.

继续往下 / Go deeper

“可商用”不是一个词，是四个权利：商用、修改、转售、独家。很多订阅只给“商用”，不允许转售/独家；你把它放进客户项目，可能违反条款。采购表要逐项打勾，不要只看销售话术。

数据条款比输出权利更危险。客户素材/演员肖像/未公开产品图，如果被用于训练，可能侵犯客户保密/肖像权。合同要写“不用于训练/可删除/不跨境”，并保存删除证明。

验收 / Checks

  • 合同有输出权利四项。
    Contract has four output rights.
  • 数据训练/留存/跨境写清。
    Data training/retention/cross-border stated.
  • 停运通知/导出/替代写清。
    Sunset notice/export/replacement stated.
  • 责任上限/赔偿/终止写清。
    Liability cap/indemnity/termination stated.
