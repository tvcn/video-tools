适用与不适用 / Fit and no-fit

  • 想知道“凭什么说这个模型好”的读者。
    Readers asking what evidence supports a model claim.
  • 要复现测试、提交样本的创作者/厂商。
    Creators/vendors wanting to reproduce or submit samples.
  • 不适用：想要一张永久排行榜的人。
    Not for: people wanting a permanent leaderboard.

怎么做 / Do this

  1. 选六类镜头：人脸、手、运动、产品、文字、长镜头。
    Pick six classes: face, hands, motion, product, text, long take.
  2. 每条提示写死：主体/动作/光/机位/时长。
    Freeze each prompt: subject/action/light/camera/duration.
  3. 每个模型每类跑 3 次，记录失败类型。
    Three runs per model per class; log failure type.
  4. 至少 2 人盲评，1–5 分，不看模型名。
    At least two blind raters, 1–5, without model names.
  5. 发布批次日期、模型版本、价格读取日期。
    Publish batch date, model version and price read date.

别踩 / Avoid

  • 只放最好一条；这不是测试，是广告。
    Showing the best clip only; that is an ad, not a test.
  • 不同模型用不同提示；分数不可比。
    Different prompts per model; scores are not comparable.
  • 把一批分数当永久结论；版本/价格每月变。
    Treating one batch as permanent; versions/prices change monthly.

继续往下 / Go deeper

测试协议的第一价值是“可复现”，不是“给结论”。同题、同参考、同分辨率、同次数，任何一项不同，分数就不能横比。我们把提示词、参考图、模型版本和失败类型一起发布，读者可以自己重跑。

盲评的作用是去掉品牌偏见。把模型名遮掉，只给成片和评分表；如果两位评审对同一批片子的分差超过 2 分，先校准评分标准，再继续。

验收 / Checks

  • 六类镜头、3 次/类、2 人盲评都有记录。
    Six classes, three runs, two blind raters recorded.
  • 失败类型有定义，不只写“不好”。
    Failure types defined, not just “bad.”
  • 模型版本、日期、价格读取日公开。
    Model version, date and price read date published.
  • 页面明确“不做跨批次排行榜”。
    Page states no cross-batch leaderboard.
