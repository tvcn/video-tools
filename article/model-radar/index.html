模型雷达：2026-11 该看哪几个

适用与不适用 / Fit and no-fit

  • 制片/导演：先按交付规格筛，再看演示片。
    Producers/directors: filter by delivery spec first, then watch demos.
  • 独立创作者：先算可用秒成本，再决定订阅。
    Independent creators: calculate cost per usable second before subscribing.
  • 不适用：需要电影级逐帧控制、完整虚拟制片管线的项目。
    Not for: projects needing frame-level cinematic control or a full virtual-production pipeline.

怎么做 / Do this

  1. 写下交付：比例、分辨率、时长、是否有对白/音效。
    Write the delivery: aspect ratio, resolution, duration, dialogue/SFX.
  2. 把镜头分成五类：人脸、手部、运动、产品、文字。
    Split shots into five classes: face, hands, motion, product, text.
  3. 每个候选跑同一条 5 秒提示三次，记录失败率。
    Run the same five-second prompt three times per candidate and log the failure rate.
  4. 按“可用秒成本”排序，不按单条演示片排序。
    Rank by cost per usable second, not by a single demo clip.
  5. 复核地区和商用条款，再进入批量。
    Check region and commercial terms before scaling.

别踩 / Avoid

  • 拿总排行榜当采购结论；榜单的镜头组合不是你的项目。
    Using a leaderboard as a purchase decision; its shot mix is not your project.
  • 拿一条最好看的演示片当稳定率；至少跑三次同题。
    Judging stability from one hero demo; run the same prompt three times.
  • 只算生成价，不算重试、人工筛选和后期。
    Counting generation price only, not retries, review time or post.

继续往下 / Go deeper

雷达不是排行榜。一个模型在人物近景上稳定，不代表它在产品微距、手部动作或长镜头里同样稳定。把“镜头类型”作为第一层筛选，把“交付规格”作为第二层，最后才看价格。

2026-11 的七个候选各有取舍：Veo 3.1 强在 4–8 秒、原生音频和 4K；Kling 4.0 把单次时长推到 30 秒、10 个关键帧；Seedance 2.5 强在多模态参考和区域编辑；Wan 3.0 能读文档、1080P 成本低；Runway Gen-4.5 强在镜头编排和 Aleph 2.0 编辑；MiniMax H3 是少数开放权重、可本地跑的长片段模型；Gemini Omni 1.2 Flash 把对话式编辑和 15 秒、低价做在一起。

真正的采购表应该有三列：镜头类型、可接受失败率、可用秒成本。演示片只能回答“最好的一条能多好”，不能回答“第十条还能不能用”。所以每个候选至少跑三次同题，记录人脸、手、文字、运动四项，再决定是否进入第二轮。

验收 / Checks

  • 七个模型都有版本号、官方链接、地区与日期。
    All seven have version, official link, region and date.
  • 每个模型至少写 3 个适用镜头、3 个禁用镜头、2 个替代。
    Each model lists three fit shots, three no-fit shots and two alternatives.
  • 同题测试至少 3 次，记录失败类型而不是只打分。
    At least three runs per prompt, logging failure type rather than a single score.
  • 页面价格标注“读取日期”，不把渠道价写成官方价。
    Prices carry a read date; channel prices are not labeled official.
