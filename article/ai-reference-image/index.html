参考图与首帧：什么图能用

参考图不是“找一张好看的图”；它要能回答主体是谁、比例多少、光从哪来、背景是什么。首帧还要给运动留空间。

适用与不适用 / Fit and no-fit

  • 有产品图/人物照，但生成后总变形的项目。
    Projects with product/person photos that warp after generation.
  • 需要首帧/尾帧锁构图、锁场景的镜头。
    Shots needing first/last frames to lock composition and set.
  • 不适用：没有授权的人物照、带品牌 logo 的网页图。
    Not for: unlicensed portraits or web images with brand logos.

怎么做 / Do this

  1. 先选一张“主参考”：主体最大、最清晰、无遮挡。
    Choose one hero reference: largest subject, sharpest, unobstructed.
  2. 补一张环境参考：背景、光向、色温。
    Add one environment reference: background, light direction, temperature.
  3. 人物正脸/侧脸/全身各一张，不要十张自拍。
    One front, one profile, one full body; not ten selfies.
  4. 首帧把主体放在运动起点，尾帧留出终点。
    Place subject at motion start in first frame and end in last.
  5. 所有参考图统一比例，避免拉伸。
    Use one aspect ratio across references to avoid stretching.

别踩 / Avoid

  • 用带滤镜的自拍当参考；模型学到的是滤镜，不是你。
    Using a filtered selfie; the model learns the filter, not you.
  • 参考图比例和交付比例不一致；人物被拉宽。
    Reference ratio differs from delivery; the person stretches.
  • 拿未授权明星/博主照片做参考；法律风险。
    Using an unlicensed celebrity/influencer photo; legal risk.

继续往下 / Go deeper

参考图的作用是“减少模型猜测”，不是“让模型复制”。你给一张正脸、一张侧脸、一张全身，模型知道脸型、发型、体型；你给十张同角度自拍，它只知道一个角度，转到侧面就崩。

首帧和尾帧是构图锚点，不是表情锚点。首帧锁人物位置、背景、光向；表情和细节留给生成。把首帧做得太满，运动没有空间，模型只能原地抖。

验收 / Checks

  • 主参考短边 ≥1024，主体清晰无遮挡。
    Hero reference has a short side ≥1024 and a clear subject.
  • 人物有正/侧/全身三张，不是十张相似自拍。
    Character has front/profile/full body, not ten similar selfies.
  • 参考比例与交付比例一致。
    Reference ratio matches delivery.
  • 所有人物/产品图有授权记录。
    Every portrait/product image has a permission record.
