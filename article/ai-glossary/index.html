60 条速查 / 60 terms

术语Term
镜头 Shot一段连续画面；AI 里通常 4–30 秒。
场景 Scene同一地点/同一时间的一组镜头。
分镜 Storyboard逐格画出的镜头顺序与目的。
预演 Previz用低分辨率动态画面验证机位/节奏。
首帧 First frame视频第一帧，锁构图/主体位置。
尾帧 Last frame视频最后一帧，锁运动落点。
关键帧 Keyframe指定叙事拐点的画面。
参考图 Reference给模型的主体/场景/风格依据。
图生视频 I2V从一张图生成视频。
文生视频 T2V从文字生成视频。
视频到视频 V2V用原视频结构重绘外观。
原生音频 Native audio生成画面时同步生成对白/环境/音效。
口型 Lip-sync嘴部动作与语音对齐。
ADR后期补录对白，替代现场声。
Foley脚步/衣物/道具等拟音。
LUFS响度单位；平台常用 -14 至 -12。
LUT查找表，用于色彩转换/风格。
ACES电影级色彩管理框架。
EXR高动态范围图像序列格式。
ProRes高质量中间编码，常用 422 HQ。
Alpha透明度通道；合成边缘关键。
Roto逐帧遮罩/抠像。
Tracking跟踪相机/物体运动。
Clean plate无主体/无穿帮的干净背景板。
Set extension把场景向画外延伸。
Relight改变光源方向/强度/色温。
Color match多镜头色彩统一。
Temporal consistency相邻帧的稳定/不闪烁。
Identity consistency跨镜头同一人/物不漂。
Flicker逐帧亮度/纹理抖动。
Morph主体形状融化/变形。
Artifact生成错误/伪影。
Hallucination模型编造不存在的细节。
Seed随机种子；同种子+同参数更易复现。
Sampler采样器，影响生成路径。
CFG提示词遵循强度。
Steps采样步数；不是越高越好。
LoRA低秩微调，用于风格/角色。
Checkpoint完整模型权重。
VAE编码/解码 latent 的组件。
Latent压缩后的模型工作空间。
Upscale超分/放大。
Batch一次提交多条任务。
Queue任务排队系统。
Idempotency重复请求不重复扣费/不重复执行。
Rate limit供应商并发/频率限制。
Latency单次请求响应时间。
Throughput单位时间完成量。
VRAM显存；本地部署第一瓶颈。
Quantization量化，降低显存/精度。
Open weights可下载权重的模型。
Commercial license商用许可；注意地区/营收/署名。
Attribution署名/来源标注要求。
Deepfake合成/替换真人形象或声音。
Consent书面同意；肖像/声音/未成年人。
C2PA内容来源与编辑历史凭证。
Watermark水印；平台/版权/标注。
Safe area字幕/主体不被 UI 遮住的区域。
Aspect ratio画幅比例，如 9:16/16:9/1:1。
Bitrate码率；影响清晰度/文件大小。
Codec编码格式，常用 H.264/H.265/ProRes。
Color space色域，如 Rec.709/sRGB。
Loudness整体响度；与 LUFS 相关。
Subtitle字幕；SRT/ASS/烧录。
Roundtrip素材进 NLE/合成再回批。
Proxy低码率代理，用于剪辑。
Master母版；最高质量交付文件。
Deliverable最终交付物；平台版/母版/字幕。
Shot routing按镜头类型分配模型。
Usable rate可用条数/生成条数。
Cost per kept clip总成本/可用秒数。

别踩 / Avoid

  • 把“开源”当“免费商用”。
    Treating open source as free commercial.
  • 把“4K”当“高质量”。
    Treating 4K as high quality.
  • 把“AI 生成”当“无版权”。
    Treating AI output as copyright-free.

继续往下 / Go deeper

术语表的作用是“减少误解”，不是“显得专业”。把 T2V/I2V/V2V 混用，团队会做错流程；把“开源/商用/署名”混用，会踩法律坑。每个词一句人话，比一段论文有用。

术语会变。今天的“原生音频”可能明天叫“同步音频”；每季度把新词补进来，把旧词标“旧称”。不要为了统一而统一，读者能查懂才是目的。

验收 / Checks

  • 每条术语一句人话，不绕。
    Every term has one plain line.
  • 缩写首次出现给全称。
    Acronyms spelled out first.
  • 法律/平台术语标“以官方为准”。
    Legal/platform terms say “official source.”
  • 每季度更新。
    Quarterly update.
