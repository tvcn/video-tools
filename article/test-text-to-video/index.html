同题文生视频实测：怎么跑、怎么记

文生视频测试只回答三个问题：主体稳不稳、动作成不成立、能不能接下一个镜头。本页给固定提示、评分表和记录模板；不编造分数。

适用与不适用 / Fit and no-fit

  • 要自己跑同题对比的创作者。
    Creators running their own same-prompt comparison.
  • 需要给团队一个可复现评分表的制片。
    Producers needing a reproducible score sheet.
  • 不适用：想看“哪个模型第一”的读者。
    Not for: readers wanting “which model is #1.”

怎么做 / Do this

  1. 固定六条提示：人脸/手/运动/产品/文字/长镜头。
    Freeze six prompts: face/hands/motion/product/text/long take.
  2. 每条跑 3 次，同分辨率、同时长、同音频开关。
    Three runs, same resolution, duration and audio setting.
  3. 先记失败类型：变形/滑步/闪烁/错字/音画不同步。
    Log failure type first: warp/slide/flicker/typo/desync.
  4. 再打 1–5 分，两人盲评。
    Then rate 1–5 with two blind reviewers.
  5. 发布提示、参考、版本、日期；不凑总分。
    Publish prompt, reference, version, date; no aggregate ranking.

别踩 / Avoid

  • 每条提示不同；结果无法比较。
    Different prompt per run; results incomparable.
  • 只放成功一条；失败率被隐藏。
    Showing only successes; failure rate hidden.
  • 用“电影感”当评分项；无法复现。
    Using “cinematic” as a score; not reproducible.

继续往下 / Go deeper

文生视频的难度在于“同题”本身。模型对词序、标点、语言都敏感；一条提示翻译成英文，结果就变了。测试必须固定原文，最好中英各跑一组，并标明语言。

评分表不要只写总分。主体、动作、光、接点四项分开打，读者才知道“8 分”是脸稳还是光好。失败类型比分数更有价值：它告诉你下一次该怎么写。

验收 / Checks

  • 六条提示、三次生成、两人评分全记录。
    Six prompts, three runs, two raters recorded.
  • 失败类型先于分数记录。
    Failure type logged before score.
  • 分辨率/时长/音频开关固定。
    Resolution/duration/audio fixed.
  • 页面不出现“第一名/最强”结论。
    No “#1/strongest” claim.
