按镜头类型的提示词库

20 条可复用提示词，按人脸、手、运动、产品、文字、长镜头分组；每条只改主体/动作/光三个变量，不写“电影感”这种空词。

适用与不适用 / Fit and no-fit

  • 每次写提示都从零开始、结果不稳定的创作者。
    Creators starting from zero every prompt, with unstable results.
  • 团队需要统一提示格式、方便交接。
    Teams needing one prompt format for handoff.
  • 不适用：想要“万能神提示”的人。
    Not for: people wanting one magic prompt.

怎么做 / Do this

  1. 先选镜头类型，再选模板。
    Pick shot type, then template.
  2. 只改主体：年龄/服装/材质。
    Change subject only: age/wardrobe/material.
  3. 只改动作：一个起点一个终点。
    Change action: one start, one end.
  4. 只改光：方向/软硬/色温。
    Change light: direction/hardness/temperature.
  5. 保留“禁止项”：不生成文字/logo/多主角。
    Keep bans: no text/logo/multiple heroes.

别踩 / Avoid

  • 一条提示塞五个动作；模型平均化。
    Five actions in one prompt; the model averages.
  • 用“高级感/电影感”；不可执行。
    Using “premium/cinematic”; not actionable.
  • 让模型生成中文/英文标语；错字。
    Generating slogans; typos.

继续往下 / Go deeper

提示词库的价值是“减少变量”，不是“增加形容词”。一条好提示像镜头卡：主体、动作、光、机位、时长、禁止项。形容词越多，模型越容易平均化。

20 条模板不是 20 个秘密，而是 6 类镜头的 20 种组合。真正要学的是“怎么改一个变量”，不是背句子。把每次改动和结果记在模板旁边，三个月后它就是你的个人库。

验收 / Checks

  • 每条提示有主体/动作/光/机位/禁止项。
    Each prompt has subject/action/light/camera/bans.
  • 一条只改一个变量。
    One variable per iteration.
  • 文字/logo 不交给生成模型。
    Text/logo not generated.
  • 模板能让他人复现同题。
    Template lets another person reproduce.
