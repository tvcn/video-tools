一次生成 3 条，怎么挑

一次只生成一条，你是在抽奖；一次生成三条，你才有比较。挑片不看“最好看”，看主体稳定、动作成立、能接上下一个镜头。

适用与不适用 / Fit and no-fit

  • 每次生成很多条，但不知道怎么选的项目。
    Projects generating many takes without a selection method.
  • 需要把 3 条候选变成可剪辑素材的创作者。
    Creators turning three candidates into editable footage.
  • 不适用：只想要“最好看的一条”做封面。
    Not for: picking the prettiest single frame for a cover.

怎么做 / Do this

  1. 固定提示和参考图，只改一个变量跑 3 条。
    Fix prompt and reference; change one variable for three takes.
  2. 先看主体：脸/产品有没有变形。
    Check subject first: face/product warping.
  3. 再看动作：起点、过程、终点是否成立。
    Then action: start, middle, end.
  4. 最后看接点：能否接上一个镜头。
    Then the cut point: can it connect to the previous shot?
  5. 留下一条主选 + 一条备选，其余归档。
    Keep one primary and one backup; archive the rest.

别踩 / Avoid

  • 先看清晰度/分辨率；主体变形了，4K 也没用。
    Checking resolution first; 4K does not save a warped subject.
  • 只留一条，删掉备选；剪辑时没有退路。
    Keeping one and deleting backup; no fallback in the edit.
  • 用不同提示跑三条；无法比较。
    Using different prompts for three takes; no comparison.

继续往下 / Go deeper

挑片的第一原则是“可用”，不是“惊艳”。一条脸稳、动作成立、能接上的普通镜头，比一条惊艳但接不上的镜头有价值。把评分四项写在纸上，三个人各自选，选同一型的概率会明显提高。

备选不是垃圾。后期调色、稳定、补帧时，主选可能突然不可用；备选能救整个镜头。给每条命名 `shot03_takeA/B`，归档时保留提示词和参数，下一次不用重抽。

验收 / Checks

  • 三条用同一提示、同一参考，只改一个变量。
    Three takes share prompt/reference; one variable changed.
  • 主体、动作、光、接点四项都有记录。
    Subject, action, light and cut point logged.
  • 主选和备选都保留，命名可查。
    Primary and backup kept with searchable names.
  • 选中那条能接上下一个镜头。
    The selected take connects to the next shot.
