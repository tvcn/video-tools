SSD RAID：剪辑阵列

SSD RAID 是剪辑工作盘，不是归档；阵列一坏，重建比备份更贵。

只有一块阵列、没有离线备份时，不要把它当唯一素材库。RAID 解决速度或单盘故障，不解决“整个项目消失”。

先分清 RAID 与备份

  • RAID 0：速度叠加、风险叠加；一块盘坏，整组素材可能都打不开。只适合可重生成的缓存。
  • RAID 1/5/6：有冗余但仍不是备份；控制器坏、误删和勒索软件会同时影响整组。
  • 接口与散热：确认 Thunderbolt/USB 版本、持续写入和散热；剪辑阵列过热会掉速。

现场

建 RAID 0 只放工作素材，另设 RAID 1 或 NAS 做备份；跑满盘测试，看降速。

怎么做

  1. 建 RAID 0 只放工作素材。
  2. 另设 RAID 1 或 NAS 做备份。
  3. 跑满盘测试，看降速。

别踩

别把 RAID 0 当唯一存储；一块盘坏，全部素材一起没。

三种原因

针对“SSD RAID：剪辑阵列”，先按三个方向排查；每次只改一个变量，改完录 30 秒对比，看变化跟着哪个环节走。

原因现场信号5 分钟验证
RAID 0 当唯一备份一块盘坏，全部素材丢失RAID 0 只做工作盘，另做备份
接口带宽不够USB 10Gbps 跑不满多盘阵列确认主机接口和线材
散热不足持续写入降速，剪辑卡顿测 30 分钟持续写入

现场诊断

  1. 用 AJA/Blackmagic 测持续读写，不只看峰值。
  2. 连续写 30 分钟，记录速度、温度、是否掉盘。
  3. 确认备份存在，且恢复演练成功过一次。

修法

RAID 不是备份，是可用性和速度工具。先保证有一份独立备份，再谈阵列。

  1. 双盘 RAID 0 做工作盘，另用单盘/ NAS 做备份。
  2. 用 10Gbps 以上接口，线材和扩展卡都要匹配。
  3. 给阵列留散热空间，避免叠放。
  4. 每月做一次恢复演练，随机抽一个文件。

失败案例

处理“SSD RAID：剪辑阵列”时，下面三种做法会更糟；先选一个替换动作，别同时改三个变量。

失败做法为什么会更糟替换动作
RAID 0 存唯一素材一块盘故障全丢独立备份
只看峰值速度持续写入掉速，剪辑卡30 分钟测试
用 USB 集线器带宽共享，速度腰斩直连主机

验收表

验收不是“感觉好了”，是这四项都能指认、能回放、能记录。

验收项通过线记录
持续写入30 分钟不低于项目码率 2 倍测速记录
备份至少一份独立副本备份清单
恢复随机文件能恢复演练记录
温度持续写入不过热降速手感/传感器

现场一句话

RAID 0 只负责快，备份负责活下来；两者不是一回事。

验收

  • RAID 0 只存工作素材，原始素材另有备份。
  • RAID 1 或 NAS 的备份任务在运行。
  • 满盘测试记录了写入降速幅度。
