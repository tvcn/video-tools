软件/硬件/预算：电脑、手机、存储、网络

适用与不适用 / Fit and no-fit

  • 要配电脑/手机/存储做 AI 视频的创作者。
    Creators buying a computer/phone/storage for AI video.
  • 团队要一套最低/推荐/高端配置。
    Teams needing minimum/recommended/high configurations.
  • 不适用：具体型号跑分/矿卡/超频。
    Not for: specific benchmarks/mining cards/overclocking.

怎么做 / Do this

  1. 先看内存：16GB 起步，32GB 推荐。
    RAM first: 16GB minimum, 32GB recommended.
  2. 再看存储：NVMe + NAS 备份。
    Storage: NVMe + NAS backup.
  3. 再看显卡：8GB 草稿，16GB 本地，24GB 批量。
    GPU: 8GB draft, 16GB local, 24GB batch.
  4. 网络：100Mbps 上行起步。
    Network: 100Mbps upload minimum.
  5. 最后看显示器/音频：4K/监听。
    Then monitor/audio: 4K/monitoring.

别踩 / Avoid

  • 只看显卡；16GB 内存开 4K 时间线就爆。
    Only GPU; 16GB RAM dies on a 4K timeline.
  • RAID 当备份；误删/勒索照样丢。
    RAID as backup; deletion/ransomware still loses.
  • 用 Wi-Fi 传 4K 素材；上传慢到停工。
    Wi-Fi for 4K assets; upload stalls.

继续往下 / Go deeper

AI 视频的“卡”通常发生在三个地方：内存爆、硬盘满、上传慢。显卡决定生成速度，但这三样决定你能不能工作。先加内存/硬盘，比换显卡便宜。

本地部署要看显存，但也要看模型/量化/VAE。一张 24GB 卡跑 33B H3 仍然紧张；云端 API 对大多数团队更省心。先算“每月可用分钟”，再决定买不买卡。

验收 / Checks

  • 内存 ≥16GB，推荐 32GB。
    RAM ≥16GB, 32GB recommended.
  • 素材/输出/备份三处分开。
    Assets/output/backup separate.
  • 上行 ≥100Mbps 或专线。
    Upload ≥100Mbps or dedicated.
  • 3-2-1 备份可恢复。
    3-2-1 backup restorable.
